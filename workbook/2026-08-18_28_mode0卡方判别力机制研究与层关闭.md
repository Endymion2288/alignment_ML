# 2026-08-18（28）mode-0 χ² 判别力机制研究与 χ² 层关闭

## 任务

在冻结 V2 backbone / route policy / physical_edge_deduplicated canonical 语义 /
multi-DoF update / sealed test 的前提下，只做现有 train physical + multi-track
artifacts 的机制研究：为什么 150 mm 残差的已知 0→1 错配边只有 χ²≈12.8；为什么
truth heavy-tail 与 fake 中等 χ² 高度重叠；比较 train-only 冻结的 Student-t /
Huber-Tukey / mixture core+tail 等统计判别控件（可按 station pair），联合指标为
truth retention × wrong rejection × purity × deduplicated validation closure 稳定性；
禁止再以 pull-width 全局 rescaling 修改 WLS 协方差。

## 实现

- `scripts/audit_propagation_discrimination.py`：边级数据集。对 physical source
  （tracklets+propagations）与 multi-track synthetic overlay（synthetic_tracklets+
  field_candidates）在 anchor/reference 两个 payload 上重建**同一冻结 endpoint 定义、
  ungated** 的全部相邻对 candidate，按 truth_particle_id 标 truth/fake，并与冻结
  backbone anchor 表 join 出 route_selected 标志。每边记录残差 4 分量、完整联合
  协方差（10 个独立元）、边际 pull、χ²、source tracklet state、station pair、source。
  train 84,770 边 / validation 67,251 边
  （`outputs/mc24_propagation_discrimination_{train,validation}_v1`）。
- `alignment/propagation_compatibility.py`：五种模型的统一打分（分数越高越不兼容）：
  gaussian（χ²+log|C|+const）、student_t（ν 按 pair 网格 MLE）、mixture_core_tail
  （(1-f)N(0,s_cC)+fN(0,s_tC)，EM）、huber/tukey（尺度冻结在 train truth χ² 分位）。
  veto 阈值 = train truth 分数的 99.5% 分位，按 pair 冻结进 JSON。
- `scripts/evaluate_propagation_compatibility.py`：只在 **train physical truth 边**
  （唯一物理边、无 overlay 重复）上拟合；在 synthetic overlay 上评估分离；validation
  仅一次冻结迁移；输出错配边逐分量分解、pair×payload 分离表、逐 source 表。
- `tests/test_propagation_compatibility.py`（6 个测试）：gaussian 分数解析式、
  大 ν Student-t 逼近高斯、mixture EM 回收已知尺度、veto 分位自洽、JSON 往返、
  未知 pair 判 +inf、最小统计量拒绝。全套 200 tests 通过。

## 机制结论

**错配边 χ²=12.8 的分解**（0->1，anchor）：
r = (−150.2, −0.24, −0.079, +0.002)，σ = (48.8, 493.4, 0.032, 0.575)，
边际 pull = (−3.08, −0.000, −2.47, +0.004)。mode-0 联合协方差巨大（σ_y≈493 mm），
150 mm 错配在 x 方向仅 3.1σ。其 χ²=12.8 位于 train truth χ² 分布的**中位数**
（分位 0.507）。

**重叠机制**：truth χ² 分布本身灾难性重尾——中位数 15.6（校准 χ²_4 应为 3.4）、
29% > 100、14.5% > 1000、q99 ≈ 1.3×10⁵、max 4.8×10⁷；fake 中位数 ≈ 5×10³、
q01 ≈ 6–10。fake 下尾落入 truth 核心，truth 上尾越过 fake 上尾——每个分位都重叠。

**模型比较**（pair×payload，train 与 validation 迁移一致）：
AUC(χ²) = 0.86–0.92；student_t / mixture 最多 +0.01；huber/tukey 为 χ² 单调变换
（AUC 相同）；max|pull| / |pull_x| 仅 0.55–0.59。冻结 veto（99.5% truth 保留）下
fake 拒绝率 0.3–6%；错配边不被任何模型 veto（阈值 ~10⁵）。

**依赖性**：逐 source 均匀（离群源 00150_00199 完全典型：med 15.7、P(>100)=0.196）；
anchor vs reference 几乎相同（误判依赖弱）；仅 |y|>100 mm 的边尾部更重
（P(χ²>100)=0.59）。二维（χ²×运动学）无可利用结构。

## 判定（按冻结判定树）

没有任何 train 冻结似然能可靠分离 truth 重尾与错配边 →
**明确记录：mode-0 propagation 在 χ² 层缺少足够判别信息；χ² 层调参到此为止。**
不做 compatibility-veto closure 变体（错配边在 truth 中位数处，veto 它等于拒绝一半
truth 边）。无候选 canonical propagation-compatibility model。

输出：`outputs/mc24_propagation_compatibility_v1/`（compatibility_models.json、
bad_edge_decomposition.json、separation_by_pair_payload.csv、separation_by_source.csv）。
