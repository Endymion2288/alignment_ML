# WB130 — WB129 event 12/20 传感器边界与测量帧审计

## 1. 科学问题

WB129 将固定 P seed 传播到 actual sensor surface，并比较 local component 0；但其 runtime response 没有保存有限 sensor bounds 判定，且 endpoint local y 可达几十毫米。WB130 只读取已保存 WB129 endpoint，在实际同一 ACTS geometry 中重新查询每个 sensor surface 的 bounds、`insideBounds` 与 `isOnSurface`，同时检查 local/global frame round-trip 和 measurement local component。

目标是判断 WB129 的 endpoint residual 是否来自有效 sensor active surface 上的测量帧，还是 propagation 只命中了无限平面/超出有限 sensor bounds。

## 2. 冻结范围

### FACT FROM REPOSITORY

- 只使用 WB127 exports 与 WB129 v2 curve responses；只审计 event 12（21 rows）和 event 20（30 rows），不新增 propagation/reconstruction/field query。
- runtime geometry、conditions、surface lookup 与 WB129 相同；不访问 held-out/sealed 数据，不改变 q/p、geometry、field、material、covariance、tolerance 或 allowlist。
- 每个 row 保存实际 surface type/bounds values、local endpoint、`insideBounds`、`isOnSurface`、measurement local position、local-y 与 frame round-trip。

## 3. 结果判词

### FACT FROM REPOSITORY

结果写入 `outputs/mc24_four_station_wb130_sensor_bounds_v1/`，机器 manifest 写入 `docs/wb130_sensor_bounds_result_manifest.json`。

### INFERENCE

若 endpoint 在 bounds 外，WB129 的 curve residual 不能作为有效 sensor-hit prediction；若均在 bounds 内，仍只关闭 active-surface acceptance 这一接口疑问，不能关闭 association、q/p prior、covariance、Hξ/Hθ 或 alignment solver。

## 4. 明确禁止

WB130 不重跑 propagation，不把 endpoint residual 输入 alignment solve，不恢复 WB103 bulk study，不训练 ML。
