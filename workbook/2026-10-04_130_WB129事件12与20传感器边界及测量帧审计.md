# WB130 — WB129 event 12/20 传感器边界与测量帧审计

## 1. 科学问题

WB129 将固定 P seed 传播到 actual sensor surface，并比较 local component 0；但其 runtime response 没有保存有限 sensor bounds 判定，且 endpoint local y 可达几十毫米。WB130 只读取已保存 WB129 endpoint，在实际同一 ACTS geometry 中重新查询每个 sensor surface 的 bounds、`insideBounds` 与 `isOnSurface`，同时检查 local/global frame round-trip 和 measurement local component。

目标是判断 WB129 的 endpoint residual 是否来自有效 sensor active surface 上的测量帧，还是 propagation 只命中了无限平面/超出有限 sensor bounds。

## 2. 冻结范围

### FACT FROM REPOSITORY

- 只使用 WB127 exports 与 WB129 v2 curve responses；只审计 event 12（21 rows）和 event 20（30 rows），不新增 propagation/reconstruction/field query。
- runtime geometry、conditions、surface lookup 与 WB129 相同；不访问 held-out/sealed 数据，不改变 q/p、geometry、field、material、covariance、tolerance 或 allowlist。
- 每个 row 保存实际 surface type/bounds values、local endpoint、`insideBounds`、`isOnSurface`、measurement local position、local-y 与 frame round-trip。

## 3. 结果判词

### FACT FROM REPOSITORY

结果写入 `outputs/mc24_four_station_wb130_sensor_bounds_v1/`，机器 manifest 写入 `docs/wb130_sensor_bounds_result_manifest.json`。

### INFERENCE

若 endpoint 在 bounds 外，WB129 的 curve residual 不能作为有效 sensor-hit prediction；若均在 bounds 内，仍只关闭 active-surface acceptance 这一接口疑问，不能关闭 association、q/p prior、covariance、Hξ/Hθ 或 alignment solver。

## 4. 明确禁止

WB130 不重跑 propagation，不把 endpoint residual 输入 alignment solve，不恢复 WB103 bulk study，不训练 ML。

## 5. 执行结果

### FACT FROM REPOSITORY

- event 12 的 21/21 rows、event 20 的 30/30 rows 均在实际 ACTS sensor surface 的有限 bounds 内，且 `isOnSurface(..., BoundaryCheck(true))` 全部为 true；surface type 均为 4，bounds type 均为 6，bounds values 为 `[-30.72, -63.045, 30.72, 63.045]`。
- 所有 endpoint 的 actual runtime surface transform 与 WB127 export 一致，local/global frame round-trip 最大误差小于 `1e-9 mm`；本阶段新增 propagation/reconstruction/field queries 均为 0。
- event 20 station 2 的 endpoint local y 达到 `[-62.284, 62.390] mm`，距 ±63.045 mm bounds 边缘最近约 `0.655 mm`；event 20 station 1 最近边缘约 `5.468 mm`。event 12 的最小边缘余量约 `27.204 mm`。
- 结果与独立审计保存在 `outputs/mc24_four_station_wb130_sensor_bounds_v2/recovery_v2/independent_audit.json`，manifest 在 `docs/wb130_sensor_bounds_result_manifest.json`。WB130 v1 payload-path failure 保留，v2 为修正版执行 namespace。

### INFERENCE

- WB129 的 event 20 counterexample 不是由 endpoint 落在有限 sensor bounds 外造成的；event 12 residual tail 也确实位于有效 sensor surface 上。WB129 的曲线 endpoint 至少通过了 active-surface acceptance 这一接口条件。
- event 20 station 2 接近 sensor 长边，说明该事件对 frame/association/几何微小差异可能更敏感，但这只是 sensitivity clue，不是 association 失败证据。
- local position 的第二分量仍是 strip measurement 未约束方向；endpoint local y 的大值不能直接作为一维 measurement residual。曲线 local component 0 的剩余差异仍不能归因于单一 q/p、field、geometry 或 association 机制。

## 6. 阶段判定与下一步边界

`runtime_surface_bounds = PASS`，`measurement_frame_roundtrip = PASS`，`curve_endpoint_active_surface = PASS_FOR_EVENTS_12_AND_20`。WB130 关闭了“WB129 endpoint 可能只是无限平面/超出 active sensor bounds”的疑问，但没有关闭 common-track association、q/p prior、covariance calibration、Hξ/Hθ、solver 或 multi-event qualification。

下一阶段才可考虑恢复极小规模 physical multi-event validation；不得把 WB130 结果升级为 alignment likelihood，也不得因为 event 20 接近边缘而删点、改 allowlist、调 covariance 或自由拟合 q/p。
