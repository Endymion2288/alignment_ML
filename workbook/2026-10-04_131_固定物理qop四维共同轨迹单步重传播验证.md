## 问题、假设与判词

科学问题：固定物理 q/p 的单次四维共同轨迹修正，能否解释 WB129 剩余 strip residual？假设为本合同的有限范围：全六事件的单步 correction 具有稳定导数、实际重传播符合线性预测，且未校准的条件 WLS cost 至少减半。cost 减半不是 alignment/association/covariance PASS，也没有声称残差已达到测量噪声。

每事件先从同一 seed 独立传播 nominal；与 WB129 保存 loc0 最大差须 ≤ `1e-6 mm`。四轴 full/half 中心差分步长继承 WB92 前四维 `[0.01 mm,0.01 mm,1e-5,1e-5]`，每轴两 signs × 两尺度。保存全部 endpoint、有限 bounds、call IDs、输入 seed。所有 arms 必须 finite、insideBounds、isOnSurface。总计 17×147=2499 次；最多一次 updated replay 增加 147，总预算 2646。失败 event 原样保留，其他预定 event 继续，不重试不替换。

设 `r=m-h`, `H=dh/dξ`，`A=diag(1/sigma) H diag(1 mm,1 mm,.001,.001)`。full/half 各列的 weighted relative L2 差 ≤ `.001`，norm floor `1e-7`；逐元素差也报告但不使用近零元素相对误差作筛选。只采用预定 full-step H，不在结果后挑选尺度。

采用 SVD least squares `A δ_scaled ≈ r/sigma`；relative rank cutoff `1e-8`，必须 rank 4。不得删除弱模、引入 damping/prior 或求 normal inverse。若 `max|δ_scaled|>10`，停止该 event 并报 UNKNOWN；不得缩短 correction。保存全奇异谱和弱向量。该 cap 是防止远离线性邻域的诊断边界，不能作为 alignment solver trust region。

对通过数值 gate 的 event，只重传播一次 `seed+δ`，q/p 完全相同。定义 `e=h_updated-h_nominal-Hδ`；要求 weighted norm `||e/sigma||/max(||Hδ/sigma||,1e-7)≤.05`，或 `RMS(e)≤.001 mm`。所有 updated endpoints 也须位于有限 surface bounds。要求 `Q_actual/Q_nominal≤.5`。零 nominal cost 单独报 UNKNOWN，禁止除零。报告 overall/station RMS、Q、Q/(n−4)（仅描述，**不计算校准 p-value**）、linear/actual residual、四轴 correction 和 half-step解差；不做第二次拟合。

## 成功 / FAIL / UNKNOWN 与停止

执行 PASS 与科学判词分开。FD/rank/cap/propagation gate 失败记 physical UNKNOWN；数值可用而真实单步不能满足减半/线性一致判据，记 one-step hypothesis FAIL。六事件均符合才可称此有限 hypothesis PASS。不能由六个 seen event 推广到总体。

若 FD 不稳定，停止本阶段拟合并量化其影响，不能现场改步长。若稳定但 residual 无法被一次四维 correction 解释，应优先审计不可解释空间及材料/动量/association 条件；不能现场自由拟合 q/p 或调 covariance。结果后再决定唯一下一阶段。本次不恢复 WB103 bulk、不生成 Hθ、不求 alignment update、不运行 ML。
