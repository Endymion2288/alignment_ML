## 问题、假设与判词

科学问题：固定物理 q/p 的单次四维共同轨迹修正，能否解释 WB129 剩余 strip residual？假设为本合同的有限范围：全六事件的单步 correction 具有稳定导数、实际重传播符合线性预测，且未校准的条件 WLS cost 至少减半。cost 减半不是 alignment/association/covariance PASS，也没有声称残差已达到测量噪声。

每事件先从同一 seed 独立传播 nominal；与 WB129 保存 loc0 最大差须 ≤ `1e-6 mm`。四轴 full/half 中心差分步长继承 WB92 前四维 `[0.01 mm,0.01 mm,1e-5,1e-5]`，每轴两 signs × 两尺度。保存全部 endpoint、有限 bounds、call IDs、输入 seed。所有 arms 必须 finite、insideBounds、isOnSurface。总计 17×147=2499 次；最多一次 updated replay 增加 147，总预算 2646。失败 event 原样保留，其他预定 event 继续，不重试不替换。

设 `r=m-h`, `H=dh/dξ`，`A=diag(1/sigma) H diag(1 mm,1 mm,.001,.001)`。full/half 各列的 weighted relative L2 差 ≤ `.001`，norm floor `1e-7`；逐元素差也报告但不使用近零元素相对误差作筛选。只采用预定 full-step H，不在结果后挑选尺度。

采用 SVD least squares `A δ_scaled ≈ r/sigma`；relative rank cutoff `1e-8`，必须 rank 4。不得删除弱模、引入 damping/prior 或求 normal inverse。若 `max|δ_scaled|>10`，停止该 event 并报 UNKNOWN；不得缩短 correction。保存全奇异谱和弱向量。该 cap 是防止远离线性邻域的诊断边界，不能作为 alignment solver trust region。

对通过数值 gate 的 event，只重传播一次 `seed+δ`，q/p 完全相同。定义 `e=h_updated-h_nominal-Hδ`；要求 weighted norm `||e/sigma||/max(||Hδ/sigma||,1e-7)≤.05`，或 `RMS(e)≤.001 mm`。所有 updated endpoints 也须位于有限 surface bounds。要求 `Q_actual/Q_nominal≤.5`。零 nominal cost 单独报 UNKNOWN，禁止除零。报告 overall/station RMS、Q、Q/(n−4)（仅描述，**不计算校准 p-value**）、linear/actual residual、四轴 correction 和 half-step解差；不做第二次拟合。

## 成功 / FAIL / UNKNOWN 与停止

执行 PASS 与科学判词分开。FD/rank/cap/propagation gate 失败记 physical UNKNOWN；数值可用而真实单步不能满足减半/线性一致判据，记 one-step hypothesis FAIL。六事件均符合才可称此有限 hypothesis PASS。不能由六个 seen event 推广到总体。

若 FD 不稳定，停止本阶段拟合并量化其影响，不能现场改步长。若稳定但 residual 无法被一次四维 correction 解释，应优先审计不可解释空间及材料/动量/association 条件；不能现场自由拟合 q/p 或调 covariance。结果后再决定唯一下一阶段。本次不恢复 WB103 bulk、不生成 Hθ、不求 alignment update、不运行 ML。

### FACT FROM REPOSITORY — 日志计数缺陷及 saved-only 恢复

原 controller 用 INFO `CALL_BEGIN` 行数记录 attempted calls；Athena 对每个 algorithm 的 INFO 默认限制 500 条，derivative 的 begin/end 合计超过该限制。因此原 `summary.json` 中 `attempted_propagation_calls=1602` **不是实际调用数**，原 `completed_propagation_calls=2601` 才对应完整 responses。原 summary 和冻结脚本未改、未覆盖。

新 `scripts/wb131_call_accounting_audit.py` 在 `saved_call_accounting_v1/` 独立冻结自身和原 artifacts，要求每个 request 的 arm/seed/row coverage 完整、response call IDs 连续 `1..N`、official/new counter 一致，并用缺失/重复 ID negative control 检查少算不能通过。10 个已完成 Athena requests 均通过；实际 attempted=completed=`2601`，visible log begins=`1602`。没有重跑 propagation。这是 **aggregation/interface failure + saved-only recovery**，不是 scientific falsification。原 QR auditor 的 attempted 字段也仅代表 visible lines；最终 manifest 明确保留原 summary 并采用修正后的 exact count。

### INFERENCE — 本阶段解决了什么

1. 在 1/4/16/20 的冻结局部域，actual sensor Hξ 的四维 numerical response 与一次 self-consistent trajectory replay 闭合。至少三个事件的大 nominal residual 可以被 fixed-q/p nuisance 修正显著吸收；不能再把固定 P seed 的 nominal residual 直接当作模型否证。
2. “所有事件 cost 至少减半”被拒绝，但该工程假设并不是物理模型接受标准。Event 4 初始 residual 已较小；它的 FAIL 不能被升级为 common-track physics FAIL，也不允许后验降低本阶段 threshold 来改写结果。
3. Event 8 的相对 derivative gate 失败与其 saved profile effect 很小可以同时成立；Event 12 的局部数值/更新条件则明显不成立。不能统一解释为 float interpolation，也不能通过统一增大 FD step、调 tolerance 或引入 damping 放行。
4. Event 12 大线性解和不稳定导数并不能单独区分 seed/fitted-state semantics、材料/固定动量模型不兼容、association、真实 propagation numerical error。当前缺少可用 anchor，继续对任意诊断解追 accept/reject 并不能建立 alignment-level error budget。

### FACT FROM REPOSITORY — 一个仍未关闭的源头问题

`research/wb125/PersistedProvenance.cxx` 104–108 行保存 `track->trackParameters()` 平铺列表；每个条目包含 native parameters、global position/momentum、surface、charge 和 persistent index，**没有对应 TSOS type、measurement→parameter 对照、参数 covariance 或 fit-state quality**。`research/wb125/PhysicalSeedAudit.cxx` 119–146 行按距 S0 mean-z 最近的参数选择 P source，核对 free/bound bridge；没有按 measured/filtered/smoothed/seed 语义选择。Event 12 的 selected persistent index 为 2，z 距 S0 约 `1.54495 mm`，而选定 CKF 的 S0 cluster overlap 为 0。

这不证明 P source 错误；它证明“持久 CKF 参数存在且 frame/charge/bridge 可读”与“这就是适合当前共同轨迹拟合的可信 fitted-state anchor”不是同一证据。现有 artifact 无法用 nearest-z 规则补造 exact TSOS→measurement association。

父级冻结的 `WB125/saved_corresponding_boundary_audit.json` 仍给出完整 particle association 仅 **2/6**、完整 development fixture 支持仅 **1/6**。4/8/12/16 的缺 SDO 判词仍 UNKNOWN，20 的 S2 membership 仍 11/12；S0 CKF overlap 六事件均为 0。本阶段没有读取新的 truth 或改变这些判词。
