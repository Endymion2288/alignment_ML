## 关键事实：现有 bank 已含三个同边 q/p control

`NtupleDumperAlg.cxx` 对每条 truth 边写了三个 variant：
- mode 0：重建 source 状态 + segment 拟合 q/p（含其原生协方差 transport）；
- mode 1：重建 source 状态 + truth q/p，且 `suppressQOverPCovariance=true`
  （q/p 行/列不进 transport）；
- mode 2：全 truth 状态（truth position/momentum）+ truth q/p。

因此同边 control 无需任何新 production。生产配置（NtupleDumperConfig.py）未开启
`InteractionMultiScatering`/`InteractionEloss`（默认 False）→ transport 为纯
J·C·Jᵀ，material/process noise 贡献严格为零。

## 根因判定

1. **病态 σ_y 的主导来源 = 固定 q/p seed 的 dummy 方差经磁场 transport（实现问题）。**
   所有 tracklet 的 reco q/p = 1e-5/MeV（100 GeV 占位），方差 5e-6/MeV²，即
   σ(q/p)=2.24e-3/MeV 是中心值的 224 倍（动量无约束）。mode 0 把它经 Acts
   transport 传入 (y,ty)：σ_y 492/228/225 mm。同边 mode-1 control 使其塌缩至
   16.1/0.73/0.73 mm（30–300×），而残差几乎不变（16.0→15.2 mm）——纯协方差膨胀。
2. **σ_x ≈ 23–32 mm = 方向不确定度的正常杠杆臂 transport**（两 mode 均有），0->1 处
   相对残差高估约 2×。
3. **truth χ² 重尾 = combined 协方差结构性近奇异 + 真实残差离群子群。** 杠杆臂
   transport 使 position-direction 块近退化：core 边 cond(C) 中位 3.5×10¹⁰、tail
   6.9×10¹¹，近零特征方向 0.73·tx+0.46·ty。tail（χ²>1e4，mode 0 占 1.5%）中 36%
   是真实离群（maxpull>5，x 方向 |res|≈8–10 mm 对 σ≈1 mm），64% 是中等残差被
   病态条件数放大。重尾与 q/p mode 无关（mode 1 同批边，比例 3.5%）。
4. **material/process noise = 0**（生产配置关闭）。
5. **无单位/frame/Jacobian 异常**：FD 步长 1e-4 mm / 1e-6 rad 合理，core pull ≤ 1。
   mode-1 在 0->1 的残余 σ_y 为 misalignment 相关场耦合（anchor 16 mm vs
   reference 0.9 mm；validation 复现 12 mm）。

## 修复方向（train-only 同边 control 已证明）

固定 seed 的 mode-0 协方差 transport 应抑制 dummy q/p 方差（等价于把 mode 1 的
`suppressQOverPCovariance` 用于固定 seed）：σ_y 塌缩 30–300×、残差不变，且 mode-1
在 0->1 的 x/tx pull 已接近校准（robust σ 1.01/1.07）。生产修改（固定 seed + 抑制
q/p 协方差）与只读诊断重跑留待后续小规模验证。
