## 2. Architecture of the current four-station pipeline

实际依赖链为：

```text
xAOD / event allocation
  -> Calypso TrackerAlignDBTool payload (T * Rz * Ry * Rx, mm/rad)
  -> SegmentFitRefit / SegmentsRefit
  -> NtupleDumper tracklet state + covariance
  -> FaserActsExtrapolationTool(mode 0) propagation export
  -> Python conversion / SPD covariance admission / truth or ML association
  -> physical candidate graph and route packing
  -> common-track blocks
       observed tracklet stack
       local nuisance Jacobian
       global geometry FD Jacobian
       block covariance and q/p prior
  -> Schur elimination + scaled SVD / damping
  -> left-SE(3) payload update
  -> Calypso rerefit / repropagate
  -> iteration and qualification gates
```

### 2.2 What the “physical” backend actually consumes

The official runner command includes `--refit-segments`, `--export-tracklets`, `--export-tracklet-propagation`, `--tracker-align-sqlite`, `FASERNU-04`, `OFLCOND-FASER-06`, and mode 0. C++ `NtupleDumperAlg` constructs global tracklet state from `TrackParameters.position()` and momentum ratios, and propagations are exported. However `WB86OfficialPhysicalBackend._run()` parses `tracklets.root` via `parse_converted_tracklets()` and returns those tracklet states. The exported `propagations.root` is not consumed by `predict()` or the alignment blocks. This distinction is decisive: physical execution is established; physical common-track likelihood evaluation is not.

1. **“Official Calypso/ACTS backend” is not equivalent to “physical common-track likelihood.”** The first is established as command execution; the second requires predicted common-state propagation and fitted local-state response entering the same residual/Jacobian contract. Current code does not show that.
2. **A converged solver status is not a correct geometry estimate.** WB87 events 657 and 1104 demonstrate inherited large rotation errors at WB86/WB88 stops. WB88’s floor clause did not create those errors, but it also did not remove them.
3. **Zero/numerical-floor chi2 is not a calibrated GOF.** WB86 `chi2` is computed from raw residual blocks before update plus survey terms, not a profiled post-fit independent objective; `ndof` is naive and does not account for dropped modes, damping, or effective prior degrees of freedom.
4. **`fd_rel_max_from_blocks` is not a finite-difference stability test.** `alignment/wb86_official_execution.py:294-304` returns zero for all finite Jacobians. WB86’s reported FD gate therefore has no evidentiary strength.
5. **Empty-stratum coverage values are not observed zero coverage.** WB86’s screening implementation encodes empty empirical coverage as zero, which contributes to physics screening FAIL. It is a consequence of an unanalyzable stratum, not a measurement of zero probability.
6. **The WB86 technical hash fields are protocol constants, not necessarily worker-observed source hashes.** `wb86_event_worker.py` records `EXPECTED_HASHES`; retry acceptance checks sealed hash but does not bind every retry to the current source-code tree. 7. **The WB87 sample is not representative.** It contains 13 event indices deliberately selected from WB86 strata, including two execution refusals and a rotation outlier. Its census cannot support a statistical claim about 2394 events.

## 7. Mathematical audit

### 7.1 Parameterization, gauge and chart

The current four-station production chart uses station payload six-vectors `(dx,dy,dz,rx,ry,rz)` with `T * Rz * Ry * Rx`, left-applied as `T_new = Exp(xi) T`. Four-station relative diagnostics use a reference-station chart with 15 admitted relative modes; unconstrained 20/24 dimensional charts contain weak dz-like directions and are not qualified. `dz` is either fixed or a finite 5 mm survey prior; these are different statistical models.

**FACT — actual WB86 fitted global increments.** `alignment/wb85_physical_qualification_protocol.py::chart_parameter_names` 调用 `common_track_solver.parameter_chart`，按station再component排列；S0 reference始终不进入自由列表。以下translation单位mm、rotation单位mrad，写入payload前转为rad。

| family | fixed_dz chart | finite_survey_prior chart |
|---|---|---|
| identity / identifiable_translation | `(s1_dx,s1_dy,s2_dx,s2_dy,s3_dx,s3_dy)`，6D | 每站顺序`dx,dy,dz`，S1/S2/S3共9D |
| identifiable_rotation | `(s1_rz,s3_rz)`，2D | `(s1_rz,s1_dz,s3_rz,s3_dz)`，4D |
| weak_jg_diagnostic | `(s3_dx,s3_ry)`，2D | `(s3_dx,s3_ry,s3_dz)`，3D |

未列component的**增量**固定为0，不保证有限left更新后的Euler/translation分量完全不动。局部 nuisance名为`(x_mm,y_mm,tx,ty,q_over_p)`，每track五维，由Schur消元并返回增量；official路径没有定义供ACTS使用的这五维共同参考面状态，也未把返回增量喂回prediction。survey约束作用于保留的dz方向；q/p Gaussian prior作用于局部第5维。受控injection的truth只用于生成输入、选关联和报告误差，不是local nuisance可用的拟合真值。

The physical meaning of a common left transform depends on the fixed lab field/material. `alignment/common_track_geometry.py` correctly warns that algebraic `g_i^{-1}g_j` invariance is not automatically a physical gauge. WB49–50’s relative closure is therefore a chart result, not proof that a fixed-field detector has 15 freely observable modes.

### 7.2 Common-track solver

`schur_reduce()` implements the standard local/global block elimination with covariance whitening and q/p prior. Unique `measurement_id` hits are deduplicated and covariance blocks are required SPD. These are positive implementation facts.

The global normal is scaled by 5 mm translations and 60 mrad rotations, then solved with `scaled + 1e-8 I`. **Exact rank rule:** `keep = spectrum_damped > 1e-12 * data_spectrum[0]`；比较的左侧是加 damping 后的奇异值，右侧尺度来自未加 damping 的最大奇异值，并不是直接截断未正则化 spectrum。若 `1e-8` 大于该阈值，真实 null mode 可能被 ridge 抬到 retained；反之仍可 drop。存储的 `condition_spectrum` 同样来自 damped normal。No explicit PSD check is made for the global Schur normal before SVD inversion; an indefinite normal could therefore receive a numerically finite inverse. Covariance is returned at the pre-update twist chart and is not pushed forward through the nonlinear payload/Euler chart update.

`chi2` is accumulated as raw `r^TWr` at the current linearization plus prior terms, while `ndof = measurements - nuisances - parameters` with a small finite-prior adjustment. It does not profile local nuisance contributions, effective degrees of freedom from damping/rank, or independent held-out residuals. This is acceptable as a solver diagnostic but not as a calibrated post-fit GOF without a separate contract.

The reconstructed local nuisance is computed from `xi_inv @ (local_rhs - cross @ update)`, but the official path sets q/p prior mean equal to q/p at linearization, masking the prior RHS issue. The mathematical Schur code is therefore more general than the official physical call path.

### 7.3 Finite differences and SE(3)

Toy `linearize_track()` computes local nuisance derivatives by finite differences of a transport function; official physical blocks compute global one-sided FD by rerunning the backend. The local derivative is not similarly physical. Translation/rotation parameter scales are explicit, but the FD step `0.01` is a mixed chart convention and needs an independent response study at the actual physical output interface. `se3_log()` checks determinant and homogeneous row but has limited near-π handling and no explicit orthogonality projection; the WB87 large-rotation cases make this a material test target.

### 7.4 Nonlinear iteration

The official loop is `solve -> left-SE(3) update -> rerefit/repropagate`, but it keeps WB84 observed measurements fixed, ignores `solution.local_nuisances` in the physical rerefit, and relinearizes against tracklet predictions generated by the backend. That can be a coherent paired response experiment; it is not yet demonstrated to be the minimization of the declared common-track likelihood. This is the principal mathematical contract gap.

**FACT — stopping semantics.** `scaled_update_norm` 是各global increment除以5mm/60mrad后的Euclidean L2；小于1e-3意味着单分量至少受5μm/0.06mrad量级限制，但这是parameter stationarity，不是truth accuracy。另一条件是连续两步raw pre-update chi2相对变化<1e-3；旧rule在previous=0时返回None，不能停止。WB88给这个objective-stationarity条款补absolute分支；没有新增物理residual/whitened innovation stationarity，也没有验证local-state stationarity。rank、bias及physics screening是另层门，不能把两条stationarity成立解释为几何正确。证据：`common_track_solver.py::scaled_update_norm`，`wb86_official_execution.py::iterate_official_event`，`wb88_convergence_policy.py::objective_stability/evaluate_policies`。

### 7.5 Algebra validity versus physical-model validity

在 `r=m-h` 且 `H=∂h/∂parameter` 约定下，线性 model 为 `r-Hξδξ-Hθδθ`。令 `A=HξᵀWHξ+Pξ`，`B=HξᵀWHθ`，`C=HθᵀWHθ`，正确 reduced system 是 `(C-BᵀA⁻¹B)δθ=bθ-BᵀA⁻¹bξ`。`schur_reduce()` 正是这个符号与消元，`test_schur_matches_joint_with_noise` 验证 dense joint agreement。这里没有发现 Schur 符号错误；错误/缺证发生在输入给该代数的 h/Hξ/Σ 和 nonlinear chart interpretation。

official 人造 Hξ 的第5列（标成 q/p）直接作用第5个观测行，即排序中的下一站 x；第2站以下又加0.25的坐标位置选择，与应有杠杆臂、曲率、单位均无对应。它会数值上消除五个方向，却不是 common trajectory 的五个物理自由度。由此计算的 covariance 和 retained modes 不能直接当 alignment physical uncertainty。`QP_PRIOR_SIGMA=0.001` 在 toy `(q/p≈0.1)` 里约百分之一；official ingestion 原样读 `q_over_p_per_mev`，无单位换算，fallback `0.1` 与同一个 sigma 一起使用。0.001/MeV=1/GeV，不能沿用 toy 的“percent-level beam prior”解释。合同尚未定义统一 momentum units；这不是已经证明 ACTS mode0 本身有1000倍错误，而是 Python nuisance/prior语义不合。

covariance 使用 admitted hit 的 block-diagonal4×4，并非传播输出 covariance；正定检查是必要但不足条件。不同站 segment 原始cluster不重叠不自动保证材料散射/共同轨迹条件下 residual 独立；需要明确 scattering 是否进 state、process noise、还是完整Σ。模型也不含 same-event两次 rerefit 的 cross-covariance。WB86 translation成功子样本 pull width fixed `3.6183806e-13`、finite `3.2253026e-13`，几乎确定性恢复而无单位宽度：**支持 paired-response noise cancellation，反驳该子样本是 N(0,1) calibrated pulls 的说法**；不能把原因唯一归到 covariance 过大，因为 h结构和复用本身已变。

有限 survey prior 代码以 `se3_log(payload)[2]` 为 absolute residual，但只给对应 dz 对角加 `1/σ²`；非零 pose 时这个 log 分量对 left twist 的导数不是总为单个单位向量，缺 cross-derivative。local nuisance back-substitution 又没有把 `_apply_qp_prior` 的非零 prior RHS 带回来；mean=current 的 official case屏蔽这个错误，不能据其不触发证明通用函数正确。`apply_parameter_update`/error helpers 的 `zip` 不核对长度，unknown component尺度回落1，均有 contract-risk，暂无实际 WB86 length mismatch 证据。

`fixed_dz` 实际固定每步 twist 的 v_z，而不是有限更新后的 payload translation z。`Exp(v,ω)` 有 `V(ω)v`：WB87 event358 的 `dz=-0.5*dx*ry=-2.000011833e-5 mm` 对记录差 `7.8e-14 mm`。因此这个 tiny floor 不是毫米级 weak-mode failure；但其含义与“dz held at survey value”文字不严格一致。Newton increment、Euler payload和 Lie-log residual三种量须分别定义，large rotation时更不能混用。WB86 投影及 covariance 是参数分量/Euler值配 pre-update twist covariance，WB82 contract要求 finite Lie-log误差；该非线性pushforward缺失也是 pull语义限制。

## 13. Current dominant blocker

**Dominant blocker: an unverified physical measurement-model contract.** The official pipeline produces real reconstructed tracklets and propagations, but the current alignment estimator uses tracklet rerefit responses as global predictions and a synthetic local nuisance Jacobian. Until a common-state prediction and local-state response are demonstrated at the exact measurement surface, neither convergence nor chi2 calibration has the intended scientific meaning.

**Secondary blockers:**

1. Rotation pathology and nonlinear refit discontinuities, evidenced by WB33 large-severity failures and WB87/88 indices 657/1104.
2. Rank/dropped-mode semantics and weak JG/dz identifiability, evidenced by WB49, WB86 dropped modes and WB83 weak-mode failure.
3. Independent physical statistical qualification: WB86 statistical layer is null; WB83 toy qualification is FAIL and physical replicas were not used there.
4. Association/ML readiness: all current four-station ML promotion gates failed or remain diagnostic.

**Known pathology that does not block the next experiment:** WB88’s numerical-floor behavior can be tested in a later protocol, but it should not be the first experiment because it presupposes a valid physical Jacobian/likelihood.

## 16. Roadmap to eventual physical qualification

1. **Retrospective mechanism studies (already done):** WB65, WB71, WB73, WB76, WB80, WB87, WB88. Preserve their conclusions and data roles; do not reuse them as independent qualification.
2. **Measurement-model development validation (next):** Route A contract study with explicit propagation/local-state identity and physical Jacobians. A failed contract requires redesign before any convergence claim.
3. **Prospective convergence-policy validation:** after Route A success, preregister WB88-style floor/rebound semantics, rotation guards, max iterations, rank reporting and failure adjudication on a new source/event cohort. Do not choose constants from the new trajectories.
4. **Large-sample physical validation:** use fresh events not used in method selection; prefer source-disjoint coverage to assess source transfer (mandatory for an ML transfer claim, not a logical prerequisite for a narrowly declared truth-only population). Ensure enough events under every identifiable stratum without post-hoc replacement by solvable ones. Report analyzable, execution refusal, dropped mode and nonconvergence separately; `n<200` without other failure remains UNKNOWN under the frozen WB85-style rule.
5. **Independent held-out physical qualification:** freeze corpus, code hashes, external Calypso/material identity, statistical rule, strata and thresholds before opening a new held-out cohort. Statistical qualification must be evaluated only if execution layer is analyzable or protocol explicitly declares UNKNOWN.
6. **Physics screening and oracle closure:** keep execution, statistical and physics screening as separate gates. A global PASS cannot average away catastrophic rotation, dropped identifiable modes, or missing-hit identity failures.
7. **ML comparison:** only after the physical truth-associated oracle and association-independent likelihood are qualified. Use source-disjoint training, a development set already known to be opened, and a new untouched blind. ML may not repair or conceal a truth-only failure.

已完成的 retrospective studies 无须为形式完整而重做；新的物理合同、objective/covariance 验证和独立 qualification 不能由旧 toy 或 seen-data replay 替代。大样本 development 与独立 held-out validation 可在最终协议冻结后合并为一个具有足够统计量的新资格化设计，避免无必要地消耗多个新数据集。ML comparison 可完全跳过，仍能完成 truth-associated 物理对准资格化；只有目标进入 ML 才是必需。WB74 仍保留有限 family-transfer PASS，后来的失败限制其外推而不抹去历史结果。
