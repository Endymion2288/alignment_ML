## 问题

WB120 已支持两个彼此独立的问题，但停在 `mixed/inconclusive`：

1. 高 \(p\) 下曲率信息不足（sign flip 随 \(p\) 与 \(\lvert q/p_{\rm truth}\rvert/\sigma\) 恶化）
2. 报告的 native 5×5 / \(\sigma(q/p)\) 严重失配（pull RMS 955，coverage 0.415/0.659）

S2E 要把它们拆开，回答：

- \(q/p\) **本身**不可辨识到什么程度？
- 当前报告的 \(\sigma(q/p)\)/5×5 **为什么不能**表示这种不可辨识性？

关键检验：在**完整三站、18-hit、无明显拓扑缺陷**的条件子样本内，高 \(p\) sign flip 是否仍随 curvature significance 单调恶化。若仍存在，则定义为 **intrinsic curvature-information limit**，不能归因于 candidate topology。

测量级曲率 significance 优先用 \(\lvert q/p_{\rm fit}\rvert/\sigma(q/p)\)；\(\lvert q/p_{\rm truth}\rvert/\sigma\) 只作 MC diagnostic 对照。禁止仅凭 condition number 大就认定 covariance 错。

C 的尺度窗在看 batch 前收紧：只接受“重标后像高斯”，拒绝“把 RMS 955 乘 \(10^{-3}\) 得到过覆盖”的假救援。这是为了区分全局单位 bug 与胖尾，不是事后改门控。

## Covariance provenance（源码锁定，无新 dump）

Pinned Calypso `40892527e9c65409afd2378a2abfc25ddbddac03`：

1. `CreateTrkTrackTool::ConvertActsTrackParameterToATLAS`（`CreateTrkTrackTool.cxx` 104–126）
   - Acts bound 6×6 → `topLeftCorner(5,5)`，丢掉时间
   - 注释写 “Convert … to GeV”，实际是 Acts \(1/\mathrm{GeV}\) → Trk \(1/\mathrm{MeV}\)
   - \(C_{i4}\times 10^{-3}\) 再 \(C_{4i}\times 10^{-3}\)，故 \(C_{44}\times 10^{-6}\)（一致 Jacobian）
   - 该 5×5 **不经 bound→curvilinear Jacobian** 直接塞进 `Trk::CurvilinearParameters`
   - \(q/p\) 本身基不变，故 \(C_{44}\) 不应因 bound/curvilinear 标签改变；交叉项 / 条件数可以变
2. `CKF2.cxx` 268–297 + `addFittedParamsToTrack=true`
   - 可选把 CKF target-plane 拟合参数作为 Hole TSOS 放到 `front()`
   - 随后 `KalmanFitterTool::fit` refit
   - refit 成功：`createTrack` **不带** fittedParams，`front()` 是第一条 MOT smoothed state
   - refit 失败：保留原 CKF track（可能仍是 target Hole 在前）
   - dump **没有** `kf_refit_succeeded`
3. `KalmanFitterTool`
   - seed 来自 `front()`，平面在 \(z_{\mathrm{front}}-10\)
   - 回到 Acts：\(C_{i4}/=10^{-3}\)（逆 Jacobian）
   - 输入协方差 \(\times 10\)
   - 可疑 loc seed：`params(0)=center[locY]`，`params(1)=center[locX]`（表面中心，不是径迹 loc）
   - 输出再次经过 `CreateTrkTrackTool`

因此：缺 \(10^3/10^6\) 的**全局**单位错误会把**所有** pull 同标度缩放。WB119 中位数 \(\bar z\approx -0.07\)、41.5% 已在 1σ 内，已经反对这种全局错误。\(C_{44}\) 基不变，bound-当-curvilinear **不能**解释 pull RMS 955。剩下的 CKF-vs-KF-refit / Acts native 6×6 需要新字段才能贴标签，但**不能单独改变 A vs D**。
