## 接入审计（代码级）

### 观测过滤：绝不能沿用「只留 station 0」

`alignment/route_selected_update.py` 的 field-edge / anchor-selected reader
在 `source_station not in movable and target_station not in movable` 时丢边。
历史 IFT 扫描 `movable_station_ids=[0]`，因此 **1→2 与 2→3 会被静默丢掉**。
单测 `test_field_edge_observations_keep_movable_source_and_align_by_edge_provenance`
已经固定了这一旧行为。

本 bank 的 `scan_plan.json` 是 `four_station_v1` +
`movable_station_ids=[0,1,2,3]` + 空 `reference_station_ids`。同一 reader
在四站 movable 下保留全部相邻边。新增单测
`test_four_station_movable_keeps_downstream_selected_edges`：movable=`[0]`
只剩 0→1；movable=`[0,1,2,3]` 同时保留 0→1、1→2、2→3。

`scripts/run_route_selected_multidof_update.py` 从 plan 读 movable。
`four_station_v1` 现在强制 movable 写回 `[0,1,2,3]`，即使求解图丢掉某一站
的 5 个坐标。**删列是求解期坐标，不是把该站从观测里拿掉，也不是该站物理
真值。**

### 求解列：15 维，不是无约束 20 维

旧 CLI 默认吃 plan 里全部 `alignment_parameter_specs`（24 列，含 survey
`dz`）。若不拦，未知关联会重新变成不可用的 20/24 维。新增
`alignment.four_station.require_four_station_route_selected_contract`：

- 必须是 `four_station_v1`、mode-0、movable `[0,1,2,3]`
- 必须 `--only-parameters` 恰好为 S0 或 S3 参考站图的 15 个名字
- 必须 `physical_edge_deduplicated`
- 拒绝 20 维自由名、拒绝 `replica_weighted`、拒绝 IFT-only movable

旧 IFT 路径不填 `alignment_formulation`，行为不变。

### Candidate / V2 图

冻结 V2 本来就在 `ALL_STATION_PAIRS`（含非相邻）上建图、只在相邻三边上
做 unit-capacity route。`station_path=(0,1,2,3)`。不需要为四站改模型，只要
inference 吃的是四站 physical 边。

### Identity physical bank，不做 overlay

V2 训练用过 synthetic overlay。本阶段科学问题是「同一物理 bank 上四站都
可能错位」，因此 association 直接指向现有 `tracklets.root` /
`propagations.root`（identity，无 overlay、无新 Athena）。物理 ROOT 没有
`origin_*` 列；anchor-selected reader 现在与 backbone 一致：缺 origin 时回退
到 `(run_id, event_id, tracklet_id)`。这不是生产扩容。

## 预注册（看 held-out association 之前）

`configs/physical_refit_four_station_unknown_association.yaml`

只在三个已有 payload 上跑冻结 V2：

- `iteration_00_reference`（本 bank 自己的 nominal，不是物理真值站）
- `iteration_00_closure_relative`
- `iteration_00_closure_relative_plus_common`

Association-only 闸门（相对 **本 bank 自己的 nominal**，禁止用 held-out 调阈）：

| 闸门 | 值 |
| --- | ---: |
| raw 完整 truth-chain recall | ≥ 0.90 |
| 相邻站对 truth-edge recall | ≥ 0.90 |
| vs nominal efficiency 下降 | ≤ 0.10 |
| vs nominal complete-track purity 下降 | ≤ 0.05 |
| vs nominal fake-rate 上升 | ≤ 0.05 |
| 选中边必须含 0→1、1→2、2→3 | 硬性 |

失败分层：

1. raw candidate recall 掉 → propagation / candidate
2. truth 边在、V2 score/route 相对 nominal 崩 → association domain shift，
   **这时才允许规划** 四站感知 GPU 重训
3. association 稳定但 15 维 `ΔT_ij` 失败 → alignment / 线性化，应在新
   current geometry 附近重做 physical FD；禁止调 V2 或放宽 capture

15 维 WLS：anchor-selected 边 + 现有 FD 探针，S0 图与 S3 图都解，最终只评
`ΔT_ij`。残差下降只记 DQ。左乘 common SE(3) 必须保持相对表。
