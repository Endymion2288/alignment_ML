# Workbook 127 — 四站逐 strip 测量与直线压缩预测闭合

## 1. 唯一问题与范围

WB126 的唯一后续建议是回到同六事件、同 allowlist 的逐 strip measurement/prediction 闭合。本阶段固定 indices 1/4/8/12/16/20 和原 cluster IDs，读取实际 EDM；导出 cluster local/global position、local covariance、RDO、detector-element frame，并用已保存 WB125 P nominal mean-z state 作**固定 z 的全局直线压缩预测**。它回答测量对象和压缩接口是否可重建，不声称完成 ACTS 曲线 propagation。

## 2. 冻结判据

机器合同为 `configs/research_review/wp127_strip_measurement_contract.json`。每个 allowlisted cluster 必须唯一、station正确、实际 event header与fixture一致；detector frame必须刚体、单位mm；`localCovariance(0,0)`须有限正值；RDO identity保存。P seed、geometry/field/conditions、q/p、allowlist与WB125固定；本阶段不调用 propagation，只有六次事件读取/导出。

从每个cluster保存的 `globalPosition` 与 sensor transform 得到 local position交叉检查；预测为 P 的 `(x0,y0,tx,ty)` 在 cluster global z 的直线位置，转换到 detector local frame。局部测量分量0与预测分量0差值只作 residual，保留原单位；不对 residual设科学 PASS cut。直线预测不代替 ACTS curve-on-hit，若测量闭合而残差仍大，下一阶段才做 bounded actual-surface propagation。

同时独立按源码合同从导出行重建 `N=AᵀWA` 与 `b=AᵀWu`，其中 `A=(sinAlpha,cosAlpha,z*sinAlpha,z*cosAlpha)`、`u=y*cosAlpha+x*sinAlpha`，与实际 WB91 `raw_normal`/`raw_fit` 比较；缺逐行 angle/RHS 或 source fragment 不一致则 UNKNOWN。N/RHS closure 是保存/导出接口证据，不是 calibrated likelihood。

## 3. 已知限制与禁止项

local component、stereo sign、side、pitch、detector transforms来自实际 detector element；不从 filename/truth猜测。只使用现有 six seen inputs，不读held-out/sealed，不修改 production/旧outputs/workbooks，不增field query/ACTS calls，不调整C/q/p/tolerance/FD/threshold，不解alignment/ML。缺SDO与association判词原样带入，不能因导出成功升级共同粒子资格。

## 4. 前瞻状态

**PREREGISTERED / NOT_EXECUTED。**成功只表示实际 measurement export 和固定直线压缩合同闭合；不表示物理曲线模型、Hξ/Hθ、covariance calibration 或 alignment likelihood通过。若 export execution失败，保留 infrastructure UNKNOWN；若 closure失败，停止并回到 measurement source；若闭合但 residual在真实 units仍大，唯一后续是少量 actual sensor-surface ACTS propagation，不在本阶段偷偷加入。
