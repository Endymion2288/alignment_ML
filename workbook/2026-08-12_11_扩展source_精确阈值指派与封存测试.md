## 范围与不变量

本轮仍不启动 Transformer。所有样本都来自真实物理链：

```text
SCT_ClusterContainer -> SegmentFitRefit -> SegmentsRefit -> NtupleDumper
-> FaserActsExtrapolationTool(mode 0)
```

平移、residual surrogate 或 raw-hit 重建。训练、验证、测试按原始 xAOD source 文件
隔离，且每个 synthetic tracklet 保留 physical source-event UID provenance。

## 共享 MLP 与普通 global scan

shared `state_augmented_v2` MLP 在 CUDA 上完成三段 curriculum：`0--0.1 mm` 50
epochs、到 `5 mm` 60 epochs、到 `50 mm` 80 epochs。普通 global 单阈值扫描仍未通过
primary：最佳质量诊断为 Sinkhorn/Hungarian、`chi2 <= 250`，efficiency=`0.44675`、
inclusive purity=`0.95203`、fake rate=`0.04797`。因此仅增加 source、保持一个全局
score threshold 不能解决 station pair 间的 score scale 差异。

## 精确 station-pair 阈值向量

固定 checkpoint 后，只对 validation 做 station-pair temperature calibration、16 个离散
score threshold、3 个 unmatched penalty、3 个 Sinkhorn temperature 的搜索。每个 pair
内先做不读取 truth 的一对一 assignment，再用可加的 correct/predicted count 做 exact
Pareto 组合。

| 参数 | 值 |
| --- | --- |
| unmatched penalty | `1.0` |
| Sinkhorn temperature | `1.0` |
| threshold: 0->1, 0->2, 0->3 | `0.05, 0.20, 0.90` |
| threshold: 1->2, 1->3, 2->3 | `0.30, 0.35, 0.35` |

validation nominal：efficiency=`0.71313`、inclusive purity=`0.95075`、
inclusive fake rate=`0.04925`，首次通过预定义 primary（`>=0.70`、`>=0.95`、`<=0.05`）。
因此允许用完全冻结的配置执行一次 test。

主要是 pairwise score separation/threshold robustness，而不是 candidate gate 已经删除
所有真边。

## 限制与下一道门槛

1. `0->3` 的选择阈值为 `0.90`，在 validation/test nominal 都没有保留直接的
   `S0->S3` truth edge。该配置满足的是预定义的 *inclusive pairwise* primary，不能
   解释为完成直接四站关联或全局 track chain。
2. 每个 magnitude 当前只有一个真实 payload direction。因此 `1 mm` 未通过、`5 mm`
   通过的非单调性是有限 payload 采样，不能作为 capture fraction 或最终 capture range。
3. 结果已经满足“candidate recall 尚可但 MLP 在大错位下退化”的诊断前置条件；但本轮
   明确不启动 Transformer。
4. 下一步保持同一物理链，增加每个 magnitude 的真实 `dx/dy` direction trial，并用
   相邻站链式 association 或 route-level unit-capacity flow 定义四站完整度、capture
   fraction 和 recovery range。之后再决定是否需要 Geometry-Aware Transformer。
