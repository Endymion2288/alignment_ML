## 2. 审计问题 A：有效 WB92 contract FAIL

只对 indices 4、16、20 的保存 `validation.json` 和 `acts.json` 做独立 scalar/NumPy 重算，逐项复核：

- Hxi step-halving 的 Jacobian、scaled effect、误差和 tolerance；
- Hxi Taylor 的 full/half error、contraction 和 threshold；
- 失败发生的 station、target、方向/扰动标签和 source identity；
- 其它 station、target、negative controls、field query accounting、source/header/frame identity 是否保持 PASS；
- `acts.json` 的 seed、target frame、q/p、time、sensitive sequence、accepted/rejected step 计数是否自洽。

审计必须报告 exact stored value、独立重算值和差值。任何不一致是 artifact/scalar integrity `FAIL`，不得解释成物理机制。若独立重算一致，则机制分类只能写成 `SUPPORTED_DIAGNOSTIC` 或 `UNKNOWN`，不能自动称为 solver/geometry 缺陷。

预注册分类：

1. 所有失败只表现为 Hxi Taylor/step-halving，且 source/target/frame/query identity 与 scalar 重算一致：`FINITE_DIFFERENCE_NONLINEARITY_SUPPORTED_BUT_LIMITED`；
2. 失败伴随 target frame、seed/q/p、surface identity、field query 或 event header 不一致：`IDENTITY_OR_PLUMBING_FAILURE`；
3. scalar/JSON 不一致、缺 row 或 hash 不匹配：`UNKNOWN`；
4. 不允许因 contraction 失败而重算更小步长或放宽 `0.7` 阈值，本合同不测试修复。

## 3. 审计问题 B：index 12 `SurfaceError`

只读 index 12 的 `athena.log`、fixture、command 和 worker stderr，确认：

- EventInfo source/ordinal/header 与预冻结 identity 一致；
- geometry/global tag、sqlite、field map/cache、官方 Acts/FaserActs library identity 与 WB92 v3 一致；
- 失败前是否存在 target station、surface identifier、navigation boundary、nonfinite state 或 field query 异常；
- `SurfaceError:1` 是官方 propagation 返回的错误路径，还是 worker/IO/conditions 初始化失败；
- 日志是否显示静默 fallback、错误 event、错误 sqlite 或 stale geometry。

分类只能是：`OFFICIAL_SURFACE_EXECUTION_FAILURE`、`CONDITIONS_OR_IDENTITY_FAILURE`、`WORKER_IO_FAILURE` 或 `UNKNOWN`。没有新的 propagation 运行，不得凭日志之外的直觉选择分类。
