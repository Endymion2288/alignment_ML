# 2026-08-18 (30) mode-3 fixed-q/p seed covariance suppression：最小 physical production pilot 与冻结判据判定

## 任务

根因审计（条目 29）已证明 mode-0 的 σ_y 病态（数百 mm）来自把直线 segment fit 的
dummy q/p 方差（σ 为中心值 224 倍）穿过磁场输运，并指出修复方向：固定 q/p seed 模式下
抑制该无物理意义的 q/p 方差输运。本条目执行该修复方向的**最小真实 production 验证**，
冻结判据（全部成立才升级 canonical）：

1. residual 基本不变；
2. q/p-induced covariance inflation 明显消失；
3. truth/fake compatibility separation 或 candidate coverage 有实际改善；
4. route metrics 不退化（V2 checkpoint/calibration/route policy 全冻结）；
5. multi-DoF closure 仍通过冻结容差（physical_edge_deduplicated 语义）。

不覆盖现有 mode-0、不训练新模型、不扩 Rx/Rz/dz、不碰 sealed test。

## 实现

`calypso/PhysicsAnalysis/NtupleDumper/src/NtupleDumperAlg.cxx` 新增独立 variant
**mode 3**：source position/direction 与 mode-0 完全一致、仍用固定 reconstructed q/p
seed（native dummy 1e-5/MeV），仅设置 `suppressQOverPCovariance=true`（与 mode-1 相同的
抑制路径：FD Jacobian 跳过 q/p 列、输运协方差 q/p 行列置零）。variants 数组 3→4，
mode 0/1/2 逐比特不变。`convert_ntuple_tracklet_propagations.py` 透传 mode 列，无需改动。

## 结果

### 同边对比（pilot 物理点，truth-matched 边）

预测中心值 mode-3 与 mode-0 **逐比特一致**（523/523 记录 max|Δpred|=0；12 条传播失败
两 mode 完全相同）→ residual 恒等，判据 1 以满足定义的最强形式通过。

σ_y（propagated median, 0->1）：reference 491.0 → 0.914 mm（537×）；anchor 491.6 →
16.4 mm（30×）；FD ry_p 491.1 → 4.57 mm（107×）。判据 2 通过（min collapse 29.8×）。
mode-3 与 mode-1 的 σ_y 几乎相同（差 < 0.1%），确认 dummy q/p 方差是唯一被移除项。

校准质量（0->1 y，reference）：mode-0 pull robust σ = 0.0034（300× 过度覆盖）；
mode-3 = 1.62（接近 1，轻度欠覆盖）。**mode-3 协方差在物理上接近正确**；mode-0 的
"χ² 中位数好看"纯属巨大方差的偶然覆盖。

条件数：anchor 0->1 median 2.4e11 → 6.3e9（38× 改善），但结构性近奇异方向（tx/ty
主导）仍在；χ² 重尾未消失且更暴露：anchor truth χ² median 21.8 → 92.0，
q99 2.1e4 → 2.0e5，frac>100 0.247 → 0.490。

### Candidate coverage（pilot overlay，同一 events）

两 mode 完全一致：overall recall 0.9913，0->1 recall 0.9979；366 个失败全部为
`acts_propagation_failed`（mode 无关）。**无任何 coverage 收益**——覆盖损失来自传播
失败而非协方差拒绝。

### 冻结 V2 backbone（同一 overlay events，anchor payload）

| 指标 | mode-0 | mode-3 |
|---|---|---|
| complete track efficiency | 0.8805 | 0.1378 |
| complete track purity | 0.9705 | 0.9800 |
| fake endpoint route rate | 0.0202 | 0.0110 |
| V2 score AUC（anchor） | 0.9978 | 0.9817 |
| 0->1 association efficiency | 0.8948 | 0.2760 |

全 8 payload 合并：efficiency 0.790 → 0.103，AUC 0.9964 → 0.9795。
效率崩塌机制：mode-3 的诚实协方差把 truth 边 χ² 中位数推到 ~48–92，落入冻结模型
（在 mode-0 过覆盖 χ² 特征上训练）的"fake 样"区域，0->1 边大面积低于冻结阈值
（14617 vs 20560 条过阈），route 在首站断裂。

模型无关 candidate χ² 分离度同样略降：overall AUC 0.9546 → 0.9410（truth/fake 中位
χ² 比从 433× 缩到 137×；truth 重尾在紧协方差下更深地伸进 fake 核）。

### Route-selected closure（dedup 语义，同一 scan root/anchor/probes）

两 mode 均 capture_success=True（dx/dy 容差 0.1 mm，ry 1.0 mrad）：

| 参数 | mode-0 Δerr | mode-3 Δerr |
|---|---|---|
| ift_dx_mm | -0.0025 mm | -0.0016 mm |
| ift_dy_mm | +0.0049 mm | -0.0065 mm |
| ift_ry_mrad | -0.0027 mrad | -0.0005 mrad |

mode-3 点估计未被破坏（dx/ry 甚至略优）——anchor-selected route 集虽少但纯度高，
WLS 对 pilot 规模的统计量下降稳健。

## 判定

冻结判据 5 项中 3 项通过（residual 恒等、inflation 消失、closure 通过），2 项失败
（separation/coverage 无改善且恶化、route metrics 严重退化）→
`all_criteria_pass = false`（`outputs/mc24_mode3_suppression_pilot_eval_v1/verdict/`）。

**按冻结决策逻辑：mode-3 保留为诊断结果，不替换 mode-0 canonical。**

物理解释：mode-0 的 dummy q/p 方差输运虽数值病态，却偶然覆盖了真实残差分布
（y 残差 ~1.6 mm 相对 σ_y=491 mm 的 pull 仅 0.003）；抑制后协方差本身接近校准
（pull ~1.6），但整个冻结关联栈（V2 特征、标定、阈值）是在过覆盖 χ² 分布上训练的，
无法利用更诚实的协方差。真正可利用 mode-3 的路径需要在校准协方差候选图上重训
关联模型——明确超出本阶段范围。
