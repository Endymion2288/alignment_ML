# 多方向物理 misalignment scan 与四站 route-level 基线

## 本轮目标

在不启动 Transformer 的前提下，完成以下严格物理流程：

1. 对固定 test source 的 `0, 0.1, 1, 5, 10, 50 mm` 生成多个独立 `dx/dy`
   direction trial。
2. 每个 trial 都重新写 `/Tracker/Align` payload，并运行
   `SCT_ClusterContainer -> SegmentFitRefit -> SegmentsRefit -> NtupleDumper
   -> FaserActsExtrapolationTool`。
3. 固定已有 shared pairwise MLP、validation-only temperature calibration、
   validation-only threshold vector 和 unmatched penalty。
4. 用相邻站 `IFT -> S1 -> S2 -> S3` 的 unit-capacity route assignment 代替独立
   station-pair 或 greedy 指派。

## 实现与验证

新增：

- `baselines/route_assignment.py`：仅相邻站 edge 的连续 route 枚举与精确
  endpoint-capacity set-packing；未用 truth。
- `evaluation/route_metrics.py`：raw candidate chain、score-threshold chain、完整四站
  efficiency/purity、route fake/duplicate、missing-station recovery 的 truth-only 后验指标。
- `training/route_assignment.py`：按 synthetic event 组织三条相邻 score matrix。
- `scripts/run_frozen_route_level_scan.py`：读取冻结 artifact，拒绝 test-time calibration/
  threshold/temperature/模型选择，输出 CSV、JSON、图和 SHA-256 契约。
- `scripts/materialize_pooled_curriculum_synthetics.py`：增加 `--split`，并增加
  `magnitude_shared_across_direction_trials` overlay seed scope。这样同一幅度不同方向的
  source-track 与 random-fake RNG draw 受控；hard fake 仍由相应的真实 Acts 几何决定。
- `datasets/physical_curriculum.py`：只有显式 `require_all_splits=False` 才允许加载
  test-only manifest，训练默认仍强制三 split。
- `scripts/audit_physical_curriculum_bank.py` 和
  `scripts/audit_synthetic_background.py`：支持只读 test-only audit。

测试：`pytest -q` 结果为 `60 passed`。

## 真实物理 bank

配置：
`configs/physical_global_assignment_muon_2dfluka_curriculum_external_multidirection_test.yaml`。

固定 test source：

- `mc24_100116_00030_00039`，10 个 source event；
- `mc24_100117_00030_00039`，9 个 source event。

station 0 固定为 reference `(0,0)`；station 1--3 对每个非零幅度使用 3 个独立、归一化
direction。`0 mm` 在物理上没有 direction，因此只进行一次新 refit。每个 source 共
`1 + 5*3 = 16` 点，两个 source 共 32 个新 payload/refit/Acts 输出。

输出：

- physical：`outputs/mc24_muon_2dfluka_multidirection_test_physical_v1/`
- physical audit：`outputs/mc24_muon_2dfluka_multidirection_test_physical_audit_v2/`

audit 确认全部 32 点 complete、带 truth、tracklet covariance 正定。每个非零幅度三个
direction 合计有 57 个 refitted event、213 条 tracklet。无 `failure.json`。

对 source `100116` 的 `5 mm/test_02` 直接比较 nominal 与 displaced refit：

| Station | refit state median shift `(dx,dy)` [mm] | payload response error p95 [mm] |
| ---: | ---: | ---: |
| 0 | `(0, 0)` | `(0, 0)` |
| 1 | `(4.8633, 1.1610)` | `< 1.4e-13`, `< 1.1e-14` |
| 2 | `(-3.3355, -3.7249)` | `< 1.6e-13`, `< 1.1e-14` |
| 3 | `(1.8542, 4.6435)` | `< 4.5e-14`, `< 9.3e-15` |

mode-0 truth pair 共 51 条；residual response error p95 为 x `0.00064 mm`、y
`0.00832 mm`。这确认 scan 的几何响应来自真实 refit 和 Acts，而非 residual 重用。

## synthetic 与冻结契约

test-only synthetic 输出：
`outputs/mc24_muon_2dfluka_multidirection_test_synthetic_controlled_v2/`。

每个 payload 生成 240 synthetic event，每个 event 叠加三条不同 source muon track。source
membership 仍严格是上述两个 test xAOD，19 个 source event。background audit：
`outputs/mc24_muon_2dfluka_multidirection_test_background_audit_controlled_v2/`。

可与 truth counterpart 比较的 hard-negative 共 4595 个，`hard_chi2 <= truth_chi2` 的
数量为 0。

route 使用的冻结 artifact：

- checkpoint：`outputs/mc24_muon_2dfluka_curriculum_external_full_train_aug_mlp_validation_v1/mlp_pair_classifier.pt`；
- calibration：validation-only station-pair temperature；
- threshold：`0->1=0.05`、`1->2=0.30`、`2->3=0.35`；
- unmatched penalty：`1.0`；
- `q_over_p_mode=0`；
- route 只用 `0->1, 1->2, 2->3`，不要求直接 `0->3`。

最终 capture 判据固定为 complete-track efficiency >= 0.70、complete-track purity >=
0.95、inclusive route fake rate <= 0.05。inclusive fake rate 是所有非 truth-consistent
route 的比例，包含错误连接的真端点；fake-endpoint rate 另行诊断。duplicate rate 作为
fragmentation 指标报告，不用 test 重新设阈值。

## 结论与下一步门槛

这次已经满足用户定义的正式 Transformer 触发条件：`5/10/50 mm` 下，raw physical
candidate graph 的 complete truth-chain recall 均为 1.0，但冻结 MLP + 相邻站
route-level global assignment 的 capture fraction 全部为 0。尤其 50 mm 是 score-chain
recall 变为 0，而不是 raw candidate graph 失去 truth edge。

因此可以进入 Geometry-Aware Transformer 的对照研究，但本轮没有实现 Transformer。后续
模型必须与这个冻结的 source-disjoint physical route baseline 对比，并报告相同的多方向
capture fraction、direction spread 和四站 route 指标；不能只用单一 direction 或重新选择
test threshold 来声称扩大 capture range。
