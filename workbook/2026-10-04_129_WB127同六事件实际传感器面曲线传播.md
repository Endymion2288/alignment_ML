# WB129 — WB127 同六事件实际传感器面曲线传播

## 1. 唯一科学问题

在 WB127 已冻结的六个 seen events 和逐 strip export 上，固定 P seed、q/p、geometry、field、conditions、allowlist 与 WB125 的 `MaterialSource=None`，实际使用 `FaserActsExtrapolationTool` 将 seed 传播到每个导出 cluster 对应的 ACTS sensor surface。问题是：固定直线诊断中的 mm–cm endpoint 差异，能否由实际曲线 endpoint 解释到同一量级？

这不是 alignment solve、共同轨迹 association、covariance calibration 或 Hξ/Hθ 验证。

## 2. 冻结输入和预算

### FACT FROM REPOSITORY

- 输入是 `outputs/mc24_four_station_wb127_strip_measurement_v1/recovery_v5/events/*/export.json` 与对应 fixture，indices 固定为 `1,4,8,12,16,20`。
- 目标是 export 中全部 147 行；event 行数为 `24/24/24/21/24/30`。不按 residual 选点。
- 起点是各 event 的 WB127 `p_seed` 裸数组，在 station-0 `z_center_mm` 构造 ACTS bound state；q/p 不重新估计。
- 每一行通过 `wafer_id` 查找当前 ACTS tracking geometry 的实际 sensor surface；输入 transform 必须与当前 surface transform 一致。
- geometry `FASERNU-04`、global tag `OFLCOND-FASER-06`、field mode `FASER`、`MaterialSource=None`、tool step configuration 均继承 WB125；本阶段新增预算为 147 propagation calls、0 reconstruction calls。

## 3. 判词

### FACT FROM REPOSITORY

结果写入 `outputs/mc24_four_station_wb129_sensor_surface_curve_v1/`，每个 event 保存 endpoint、surface status、local residual、call trace 与失败原因。独立审计保存 exact row/identity/transform closure、finite endpoint、success/null counts，并和 WB127 straight residual 并列。

### INFERENCE

若所有 endpoint 成功且曲线 residual 解释直线 residual 的数量级，只能说明当前固定 seed 在实际 sensor surface 上的曲线传播可执行且具有 endpoint mechanism consistency；不能说明 track association、q/p prior、covariance、Hξ/Hθ 或 alignment solver 已可信。若出现 null、surface mismatch 或大 residual，优先级回到 surface/navigation/seed provenance。

## 4. 明确禁止

本阶段不改 q/p、geometry、field、material setting、tolerance、allowlist 或 covariance；不访问 held-out/sealed 数据，不训练 ML，不做 alignment solve，不重启 WB103 bulk campaign。

## 5. 执行结果

### FACT FROM REPOSITORY

- WB129 v2 在同六个 WB127 exports 上完成 147/147 次 actual sensor-surface ACTS propagation；全部 endpoint 状态为 `SUCCESS`，无 null、无非有限值，surface-local z 最大绝对误差小于 `1e-5 mm`。
- event-level all-row RMS（straight → curve）为：event 1 `5.284 → 0.199 mm`，event 4 `0.508 → 0.033 mm`，event 8 `1.909 → 0.350 mm`，event 12 `31.971 → 1.856 mm`，event 16 `0.569 → 0.043 mm`，event 20 `0.116 → 0.143 mm`。
- station 0 curve 与 straight 基线一致到数值精度；event 12 的 station 2 从 `28.128 mm` 降至 `0.258 mm`，但 event 20 的 station 1/2 分别从 `0.048/0.042 mm` 变为 `0.119/0.172 mm`。
- 每个 event 的 cluster order、event/run identity、147 row/call budget、`WB129_CALL_BEGIN/END` trace 均由独立脚本复核。结果位于 `outputs/mc24_four_station_wb129_sensor_surface_curve_v2/recovery_v2/independent_audit.json`；manifest 位于 `docs/wb129_sensor_surface_curve_result_manifest.json`。
- WB129 v1 的 state-vector decoding failure 保留在旧 namespace；v2 是隔离修正后的执行 namespace，没有覆盖 v1 artifacts。

### INFERENCE

- actual sensor-surface curve endpoint 链在固定六事件、固定 P seed、固定 field/geometry/conditions 下可执行，且在 5/6 events 的 downstream stations 显著降低了 straight residual。这是 mechanism consistency 与 endpoint effect-size evidence。
- 这不是 causal proof：曲线 residual 在 event 12 仍可达 `3.40 mm`，event 20 还是 straight 基线更好。残差还可能包含 seed provenance、q/p 语义、cluster association、geometry/conditions 或 measurement-frame effects。
- 因而 WB129 关闭了“是否能把固定 seed 送到实际 sensor surface”的数值/接口 blocker，但没有关闭 physical common-track likelihood、q/p prior、covariance calibration、`H_xi/H_theta`、solver、gauge/rank 或 multi-event qualification。

## 6. 阶段判定

`surface_prediction = PASS`；`endpoint_mechanism_consistency = SUPPORTED_ON_5_OF_6_EVENTS_WITH_EVENT20_COUNTEREXAMPLE`。这里的 PASS 只表示 147 个固定目标的 ACTS endpoint execution 和 identity contract 通过，不表示 alignment prediction 通过。

## 7. 下一步边界

暂不重启 WB103 bulk campaign，也不调 q/p、covariance、field、geometry、tolerance 或 allowlist。下一步应先对 event 20 counterexample 与 event 12 residual tail 做有限的 provenance/measurement-frame 分解；只有在明确曲线 endpoint 与实际 cluster measurement 的关系后，才考虑恢复多事件 physical validation。不得把 WB129 endpoint residual 直接输入 alignment solver 或 ML。
