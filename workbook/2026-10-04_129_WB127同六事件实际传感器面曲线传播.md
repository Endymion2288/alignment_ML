# WB129 — WB127 同六事件实际传感器面曲线传播

## 1. 唯一科学问题

在 WB127 已冻结的六个 seen events 和逐 strip export 上，固定 P seed、q/p、geometry、field、conditions、allowlist 与 WB125 的 `MaterialSource=None`，实际使用 `FaserActsExtrapolationTool` 将 seed 传播到每个导出 cluster 对应的 ACTS sensor surface。问题是：固定直线诊断中的 mm–cm endpoint 差异，能否由实际曲线 endpoint 解释到同一量级？

这不是 alignment solve、共同轨迹 association、covariance calibration 或 Hξ/Hθ 验证。

## 2. 冻结输入和预算

### FACT FROM REPOSITORY

- 输入是 `outputs/mc24_four_station_wb127_strip_measurement_v1/recovery_v5/events/*/export.json` 与对应 fixture，indices 固定为 `1,4,8,12,16,20`。
- 目标是 export 中全部 147 行；event 行数为 `24/24/24/21/24/30`。不按 residual 选点。
- 起点是各 event 的 WB127 `p_seed` 裸数组，在 station-0 `z_center_mm` 构造 ACTS bound state；q/p 不重新估计。
- 每一行通过 `wafer_id` 查找当前 ACTS tracking geometry 的实际 sensor surface；输入 transform 必须与当前 surface transform 一致。
- geometry `FASERNU-04`、global tag `OFLCOND-FASER-06`、field mode `FASER`、`MaterialSource=None`、tool step configuration 均继承 WB125；本阶段新增预算为 147 propagation calls、0 reconstruction calls。

## 3. 判词

### FACT FROM REPOSITORY

结果写入 `outputs/mc24_four_station_wb129_sensor_surface_curve_v1/`，每个 event 保存 endpoint、surface status、local residual、call trace 与失败原因。独立审计保存 exact row/identity/transform closure、finite endpoint、success/null counts，并和 WB127 straight residual 并列。

### INFERENCE

若所有 endpoint 成功且曲线 residual 解释直线 residual 的数量级，只能说明当前固定 seed 在实际 sensor surface 上的曲线传播可执行且具有 endpoint mechanism consistency；不能说明 track association、q/p prior、covariance、Hξ/Hθ 或 alignment solver 已可信。若出现 null、surface mismatch 或大 residual，优先级回到 surface/navigation/seed provenance。

## 4. 明确禁止

本阶段不改 q/p、geometry、field、material setting、tolerance、allowlist 或 covariance；不访问 held-out/sealed 数据，不训练 ML，不做 alignment solve，不重启 WB103 bulk campaign。
