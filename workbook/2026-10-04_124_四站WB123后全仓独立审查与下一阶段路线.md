**INFERENCE：**项目的最终目标应是：在 FASER 四站 tracker 上，用同一条有物理来源的轨迹解释唯一且正确关联的测量，在真实几何/磁场/材料/动量语义下建立可信的 prediction、`H_xi`、`H_theta`、nuisance profile 与 alignment 更新，证明多事件可恢复已知 misalignment，最后用未见数据证明精度和覆盖，再比较 ML 的额外价值。目标不能是使一本 workbook PASS，或用同一 response bank 做机器精度插值。

### 6.2 两个当前 solver 的独立反例

**FACT FROM REPOSITORY：**`alignment/common_track_solver.py:362` 的 `_apply_qp_prior` 正确给 local normal 与 RHS 加入 prior；`schur_reduce` 用了它。但 `solve_common_track:504` 回代重新计算 data-only `H_xi^T W r`，遗漏 prior RHS。

短解析控制：`H_xi=[I5;0]`、一个 global column 仅在第六测量为 1，`r=0,W=I6`，q/p prior `sigma=1,mean=1,current=0,damping=0`。独立 joint MAP 的 q/p update 应为 `1/(1+1)=0.5`；当前返回 **0**，完整正常方程在该返回点的 q/p gradient 为 **-1**。这是非零 prior gradient 时的实质错误。旧路径常设 `mean=current`，此时 RHS=0；**不能由本反例反推它造成了 WB86 历史失败。**

**FACT FROM REPOSITORY：**`solve_common_track:488–503` 对 `scaled + damping*I` 做 SVD，并用该 spectrum 判断 retained modes。解析控制让 data reduced normal 为 `diag(1,0)`：

| damping | returned retained/dropped | returned spectrum | 含义 |
|---:|---|---|---|
| 0 | 1 / 1 | `[1,0]` | 未观测模式被丢弃 |
| 默认 `1e-8` | 2 / 0 | `[1.00000001,1e-8]` | 无观测模式被 damping 计为 retained；对应 covariance `1e8` |

**INFERENCE：**当前返回的 retained rank/condition spectrum 不能直接代表 data identifiability；damping、constraint、prior 与 data spectrum 要分开。反例依赖 spectrum scale，不是断言所有历史 rank 都算错。相同 solver 的 `chi2` 是线性化点 data residual 加部分 survey 项，而非更新后的完整 profiled/MAP objective；其 `ndof` 也不能在 rank reduction 下直接当统计资格。

**RECOMMENDATION：**在未来 solver 阶段集中修复并用独立 joint normal/MAP 与真实 likelihood 验证；本次不修，也不把修两个函数当唯一下一科学实验。上游物理对象尚不可信，先修 solver 不能回答当前诊断对象是不是真实 common track。

## 8. Is the saved-only float cache interpolation audit justified?

### 8.1 优点与真正可回答的问题

**INFERENCE：**优点明确：成本低、不用再读 event，不改变保存 cell/corners/invwidth，原 float arithmetic 有实际 queries/trials 可以先重现；全部 rejected trials 也可纳入。它能隔离“同一组已经量化成 float 的输入，在固定 query 点和固定 trial start/h 上，中间乘加舍入有多大影响”，并找出条件 RKN estimator 是否可能跨原 `1e-4` margin。这是合理的 mechanism screening，比单看 ordinal cache/retry correlation 更强。

若 fixed-query predicate 翻转，严格结论是：**这个局部算术通道足以改变某个保存试探的条件 margin**。若未翻转，严格结论是：**所保存集合上的这个条件 test 未翻转**。两者都不等于真实 fieldcache 的全误差，因为 corner/invwidth 原始量化、cell选择、boundary continuity、field truth均被固定或未识别。

### 8.2 不能回答的问题

**INFERENCE：**改 field arithmetic 的自洽干预应重新计算：

```text
new B at k1
  → new k1 / first intermediate position
  → new query / cell / B at k2,k3
  → new later intermediate position / k4
  → new RKN error / accept/reject / retry h
  → all later positions and field queries
  → endpoint / FD / nonlinear profile / alignment update
```

固定保存 query positions 而重算 k/error，切断了中间反馈；甚至不一定是由一个一致新 trial 产生的 stages。因此它不能证明 self-consistent counterfactual trajectory、实际 retry 翻转、endpoint correction、true Jacobian bias 或 alignment improvement。near-threshold accept/reject 很敏感，但 threshold crossing 本身不是 effect size。即使自洽 retry 改了，两个路径也可能在同一物理预算内给出相同有效终态。

### 8.3 本审查的明确选择

**RECOMMENDATION：选择“暂停继续 numerical 下钻，先做有限的 physical common-track seed validation”。现在不优先执行 saved-only interpolation audit，也不立即改做自洽 double-cache propagation。**这不是永久禁止数值研究；是先验证研究对象和物理域。

理由：当前 dummy 100GeV、局部 S0 seed、巨大 mismatch/反号且超域 nuisance、S0 association缺口和production未连接的 likelihood，均比“float中间舍入是否翻一个保存trial”更上游。WB98已有另一pilot的 field算术 effect screening；不能用其量级否定当前event，但足以拒绝把 float 主因当默认先验。当前物理 seed对照可以使后续 numerical 实验在真实可用轨迹域上进行，并直接测四站 production 可达性，而不继续堆积单事件内部指标。

若新的物理 seed仍有显著、可复现的 endpoint/H_xi 问题，再设计**仅一个冻结数值通道的 self-consistent experiment**，配独立 reference与effect-size预算；此时 saved-onlyscreening可以作其廉价准备。现在两者都应等。

### 14.2 重启条件、effect chain 与硬停止规则

**RECOMMENDATION：**以后仅当有来源physicalseed上的问题可复现、达到明确误差预算，且与最终likelihood相关，才重启numerical机制实验。每次预注册必须同时给出：

```text
Delta propagation endpoint
   → Delta H_xi over declared local trust domain
   → Delta profiled residual / local nuisance
   → Delta H_theta / profiled normal
   → Delta alignment update / uncertainty / recovered geometry
```

前三层没闭合前，不能宣称alignmentlevel影响；H_theta/solver尚缺时，先给可计算的保守response预算，不能凭retry数判断重要性。

具体stoprules：

1. **相关性不是继续许可证。**cache/retry共现或fixedqueryacceptflip只能触发一次有明确上限的self-consistent causalprobe；不能自动触发再下一本更底层审计。
2. **提前给工程/物理预算。**在C校准与可用solver建立后，默认数值分配可预注册为每个measurement方向`<=0.1*calibratedsigma`、每个admittedalignment方向`<=0.1*其预注册recoverability/tolerance`，并在localtrustdomain和冻结seenpopulation上验证。二者是未来建议的显式预算，当前sigma/tolerance未合格，不能据此宣布现在PASS。
3. **预算满足就停。**独立referenceuncertainty本身须小于该numerical预算的0.1；包括FD±点、boundednuisance和几何perturbation。满足后，即使retry/cell序列不同也停止机制下钻，转回多event/solver。不能以内部branch一致作为最终要求。
4. **预算不满足才追因果。**一次只改变一个numerical通道，重算全部位置/query/controller，自洽测endpoint/J；若没有显著改善，不继续归因该通道，保留default并考虑其他已证据候选。
5. **有限investigation预算。**每个新微观候选最多一个screening和一个self-consistentfollowup；没有新增physical域effect或population证据，不再开第三本同候选诊断。需要扩展时先写清新可否证假设和预期决策变化，不能仅“下一节自然是…”。
6. **失败类型先分流。**identity/units/frame或physicalassociationUNKNOWN先停物理声明；target不可达先处理physicaldomain/nav；超域linearupdate先处理boundednonlinearfit；不能用更细step掩盖这些问题。
7. **不能永久仅看一个event。**mechanism支持后，在一个事先冻结、含未用于选候选的seendevelopment小集合上验证prevalence/effect；全部失败留表。仍需后续真正未见qualification。

**INFERENCE：**现有`.01339 sigma_ty`比较只是名义一个q/pstep的局部描述，既非上述已校准预算，也未经过weakmode/profile传递；当前既不能“证明float影响微小所以结束所有数值”，也不能“ratio1.77所以最高blocker”。正确决策是先建立physicaldomain和effect链。
