# 2026-08-15 多自由度全局 alignment 闭环

## 目标

从单轴 `dx/dy` 或 IFT `Ry` 的研究回到通用 station-level global alignment 主线。
当前仅激活 IFT 的 `dx + dy + Ry`，下游 S1--S3 是参考系；不新增 Transformer。

## 前置结论

- local segment `q/p` 不是可靠 measurement，物理链保持
  `FaserActsExtrapolationTool(mode 0)`。
- IFT `Ry=+-60 mrad` 时，冻结 MLP/V1/V2 的 route association 可通过 primary gate；
  `Ry` 不是现有 association failure boundary。
- 10-event joint anchor `(+2 mm, -1.5 mm, +35 mrad)` 的有限差分 closure 为 rank 3，
  scaled condition number 约 `511.8`，但恢复局部增量为
  `(+4.683 mm, +1.330 mm, -29.931 mrad)`，目标应为
  `(-2.0 mm, +1.5 mm, -35.0 mrad)`。
- 小样本中 `dx` 的 leave-one-event-out 波动约为 `-2.80` 到 `+9.55 mm`。因此该更新
  不得进入下一轮 payload。raw truth candidate complete-chain retention 仍为 1.0，
  当前问题是耦合参数的统计稳定性，而不是 candidate graph 截断。

## 本阶段实现

1. 新增 `prepare_multisource_multidof_iteration.py`：为每个原始 xAOD source 生成同一
   anchor/reference/中心差分物理计划，强制 train/validation-only 与 test 封存。
2. 新增 `submit_multisource_multidof_iteration_condor.py`：一 source 一 Condor job。
3. 新增 `run_multisource_refit_multidof_local_step.py`：聚合真实有限差分；train 确定
   update，validation 只做冻结 update 的 held-out closure。输出 candidate retention、
   rank/condition、covariance/correlation、曲率和 source/station-pair 诊断。
4. 新增 `assemble_multisource_multidof_iteration_manifest.py`：所有物理点完成后只读组装
   pooled physical manifest。
5. 新增 `physical_alignment_iteration_trainval.yaml`：只在 geometry payload 之间共享
   deterministic synthetic overlay stream，真实 state/residual/covariance 不变。
6. 冻结 backbone 命令新增 `--payload-id`，逐真实 payload 推理而不改变 checkpoint、
   calibration、threshold、dustbin 或 route solver。
7. 新增 `audit_multidof_physical_corpus.py` 与
   `run_multisource_multidof_physical_closure.py`，分别审计随机联合物理点和对各 split 的
   held-out joint point 做 source-disjoint finite-difference closure。
8. 新增 `audit_field_global_fit_contract.py`。实际 branch audit 显示当前 propagation tree
   有 26 个 branch、pairwise 所需字段齐全，但没有 transport Jacobian/source-state
   transition branch。因此当前 field-aware 更新只能是 selected route-edge consistency + WLS；
   不能把 edge χ² 求和称作独立 global-track likelihood。
