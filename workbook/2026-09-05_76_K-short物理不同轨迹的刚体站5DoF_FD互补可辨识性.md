## merged-rec physical-event identity（硬合同）

条目 75 证明 K-short merged MC24 rec 中 `(run_id, event_id)` 不是唯一
physical-event key：每个 rec 文件合并 10 个 generator job，event number
重启。因此任何 sorted `(run,event)` grouping 都不能用于本战役的
cross-geometry FD matching。

实现（`datasets/physical_event_identity.py`）：

- 每个 FD refit point 的 `enhanced_tracklets.root` ntuple 每 processed
  event 一个 entry（file order）。entry 级 occurrence = 该 entry 之前
  相同 `(run, eventID)` 的 entry 数；synthetic unique key
  `uid = event_id + occurrence * 2^20`。
- per-entry tracklet/propagation vector length 把 flat
  `tracklets.root` / `propagations.root` 的 row block 桥接回 ntuple
  entry；即使某 event 只对其中一个文件贡献行（tracklet-only event），
  两个文件的 occurrence 指派仍然一致。
- reference 与 ±FD geometry 间的 join 是 deterministic exact join
  （uid + tracklet identity + truth identity）。禁止 fuzzy join、
  nearest-neighbour join、residual-proximity join；duplicate
  physical-event identity 是 hard failure。
- 无碰撞文件中 occurrence 恒为 0，uid 等于 raw event id，canonical
  行为 bit-identical。

回归测试（`tests/test_kshort_rigid_station_5dof_complementarity.py`）
故意构造重复 `(run,event)`、tracklet-only event、跨 occurrence
misjoin 诱饵，确认：不合并、不错配、sorted loader 对该类文件
hard-fail、正确 occurrence 的 residual 精确等于设计值。

## 分析流程（先 physical closure，后 information analysis）

1. **Physical closure / provenance**：每个 pre-declared source 的全部
   FD point 完整（payload、tracklets、propagations、enhanced ntuple、
   content audit），per-source Jacobian validity 过冻结 gate，exact-join
   duplicate physical-event identity 计数为 0，无 geometry/official
   conditions write。physical chain 失败则分类为
   physical/provenance failure，不输出任何 “rank”。
2. **Canonical-only regression**：复用 frozen canonical bank（SHA 校验
   一致，不重跑 Athena），重建条目 73 分析并逐 source 比对 frozen
   rank / singular values（rtol 1e-10）/ pooled rank / frozen decision。
   这是 negative control，不是重新调参。
3. **K-short-only**：10 source 分别与 pooled 的 `A = W^{1/2} J S`、
   singular spectrum、rank、identifiable subspace、source stability
   （参照 K-short 自身 pooled native rank，不强求 rank 5）、
   slope-tertile / topology coverage stability、bootstrap / half-split。
4. **Joint complementarity**（预注册组合方式：canonical 18 source +
   K-short 10 source pooled，equal-per-source consensus）：
   - canonical ↔ K-short pooled subspace principal-angle relation
     （report-only，无冻结阈值，禁止发明）；
   - weakest canonical direction 上 K-short 提供的信息量（report-only）；
   - joint pooled rank（必要但绝不充分）；
   - joint source stability：pooled-remainder LOSO（去掉每个 source 的
     pooled subspace vs 完整 pooled subspace，rank 5 / 15° / 1.0；
     条目 73 的 remaining-vs-left-out-source 方向仍报告但不作 joint
     gate，因为低-rank canonical source 按构造留在 pool 中）；
   - joint coverage stability（slope tertile + complete-route topology）；
   - joint bootstrap / half-split stability；
   - workbook-69 stable-core independent validation，角色预注册：
     hypothesis = 18 canonical sources，independent = 10 K-short
     sources；canonical hypothesis core 必须 dimension 5，K-short
     independent set 过冻结 support/persistence/angle/missing-frobenius
     阈值。equal-per-source consensus 防止高统计 pion population 按
     track count 重新加权。
