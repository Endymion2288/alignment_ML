## 新增导出契约

1. `NtupleDumperAlg` 新增 opt-in 属性 `ExportTrackletDetails`，默认关闭，因而
   不改变普通 PHYS 输出。
2. 仅在启用 `faser_ntuple_maker.py --export-tracklets` 时，从 ghost-busted
   `Segments` 导出 `Tracklet_*` event-wise vector。
3. station 来自每个 `FaserSCT_ClusterOnTrack` 的
   `FaserSCT_ID::station(identifier)`；跨 station 的 segment 会拒绝，不由 z
   猜测。
4. state 是同一拟合 reference surface 的 global
   `[x_mm, y_mm, tx, ty]`；协方差由 native
   `(loc1, loc2, phi, theta, q/p)` 经关联 surface 上的 central numerical
   Jacobian 变换。不可安全变换的记录以
   `Tracklet_has_covariance=false` 和 NaN 标记，converter 默认丢弃。
5. 每个 hit 输出 station/layer/module 和 cluster identifier；后者是
   reconstruction-level cluster ID，不是 raw RDO ID。
6. MC 的每条 segment 独立调用 `ITrackTruthMatchingTool`，不复用 global CKF
   `t_barcode`。未匹配时 particle ID 为 `-1`，matching fraction 为 NaN。

事实；尚未导出为数值 station transform sidecar。

## Baseline 结论

1. 纯 straight-line `[x,y,tx,ty]` propagation 和 greedy one-to-one assignment
   已实现，synthetic、converter、truth ambiguity、内容审计共 4 个测试通过。
2. MC22 electron 的 `1->2`：gate 50 时 efficiency 为 3/9；宽 gate `1e6` 时
   9/9 的可评分 truth association 被保留。说明固定 50 对该样本过紧。
3. MC24 FASERnu 的 `0->1` 相同 truth candidate chi2 为约 118--1617，默认 50
   无候选。原因是该跨度跨磁场而当前模型为 straight line，不应把它解释为 station
   或 covariance 问题。
4. 由于 particle-gun 小样本的多数 candidate 共享同一 truth barcode，尚没有
   有意义的 false-pair population。当前 purity/fake rate 只对两端 truth 标签均
   已知且非重复的 match 计算；`unscorable` 单独报告。
5. 本阶段的 wide gate 只用于 schema/数据完整性诊断，绝不能作为后续物理 gate
   的固定阈值或最终 association 性能结论。
