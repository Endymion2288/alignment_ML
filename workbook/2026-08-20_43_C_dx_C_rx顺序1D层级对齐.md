# 2026-08-20 (43) Sequential 1-D contrast alignment：两个可测、不可同解的 block coordinate

## 任务

条目 42 已经否定联合 `C_dx+C_rx` Newton 步：train `|corr|≈0.97`、source-dependent
`C_rx`、validation residual 不降。本条目**不再**尝试二维法方程，也**不**引入
relative ry。把已经分别闭合的 `C_dx` 与 `C_rx` 当作两个可单独测量、但不可同时
线性求解的 block coordinate，在条目 42 已经生产完成的 `iteration_00_start` 与
`iteration_00_heldout_00` 上检验两种固定顺序：

1. `C_dx` → 写入 remaining layer payload → 真实 refit/reassociate → `C_rx`
2. `C_rx` → remaining/refit/reassociate → `C_dx`

每一步只浮动一个 contrast，另一个严格固定为当前 geometry 中的值。禁止 2-D
Jacobian，禁止把另一列当 nuisance。第一步必须真正写入恢复后的 layer payload
并重跑 `/Tracker/Align → SegmentFitRefit → SegmentsRefit → NtupleDumper →
Acts(mode 0)`；第二步在新的物理 geometry 上重新测量 1-D residual，而不是在
iteration-00 数据上代数扣除。

冻结不变：station 5-DoF、mode-0、V2、route policy、`physical_edge_deduplicated`、
sealed test、预注册 1-D capture（`C_dx` σ=0.00691 mm，`C_rx` σ=0.146 mrad）。
不碰 relative ry、layer dy/rz、layer1、module。

Remaining 公式（**不是** 1-D Newton 在 reference 上的 `proposed_next`，那会把未浮动
contrast 写成 0）：

```
remaining[floated] = injected[floated] − recovered[floated]
remaining[fixed]   = injected[fixed]
```

payload 仍是 `L0=(+C_dx,+C_rx)`、`L1=0`、`L2=(-C_dx,-C_rx)`，station 六矢 0。
train route-selected 决定共享 remaining；validation 只评价。

## 判定：停止 `C_rx` 层级主线，只冻结 `C_dx`

1. **两个内部 mode individually identifiable but not jointly identifiable in one Newton solve**
   仍然成立（条目 41 纯轴向 `C_rx` 闭合；条目 42 联合 2-D 简并）。本条目把它落实为
   sequential / block-coordinate 检验，而不是再冻病态 2-D 子空间。
2. **两种顺序不等价，且没有一个顺序在 validation 上闭合。**
   `C_rx→C_dx` 在第一步 remaining 就越出 `|C_rx|≤0.70` mrad 包络，不能生产。
   `C_dx→C_rx` 可以生产第一步，但第二步在 source-disjoint validation 上 residual
   不降、coverage 失败，train 只收回 ~7% 的 remaining `C_rx`。
3. **因此不把 hierarchy 定义为 sequential contrast alignment。** 第一步没有改善
   第二 mode：去掉 ~0.03 mm 的 `C_dx` 之后，零点 1-D `C_rx` Jacobian 仍不能解释
   联合 leftover。
4. **停止 `C_rx` 作为层级主线。** 当前唯一可靠的 IFT internal DoF 仍是已经冻结的
   **1-D `C_dx`**（条目 39/40）。条目 41 的纯轴向 `C_rx` 闭合保留为 identifiability
   事实，但不是可在真实 detector 上与 `C_dx` 顺序更新的 alignment DoF。
5. 相对 ry、layer dy/rz、layer1、module **仍不准入**。不打开 test，不重调
   V2 / mode-0 / route / `C_dx` 1-D / station 5-DoF。

回归：`tests/test_sequential_contrast.py` 8 项 + 既有 contrast/layer 测试。
Remaining 明确拒绝把 1-D `proposed_next`（未浮动列=0）写成下一几何。
held-out-only corpus 的 event UID 允许无 nominal 点。

## 因此不做

- 不生产 `rx→dx` remaining（包络外）
- 不生产第二步 leftover 的新 18 源 refit
- 不把 `C_dx+C_rx` 顺序迭代冻成官方 hierarchy
- 不引入 relative ry 来补偿 `C_rx` 失败
