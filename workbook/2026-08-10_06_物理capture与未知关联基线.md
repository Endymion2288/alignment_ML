# 2026-08-10：物理 Capture Range 与 Unknown-Association Baseline

## 目标与边界

本阶段严格不启动 Transformer。先完成真实 conditions payload 下的 physical capture-range
scan，再在同一批 payload 的 refit 结果上做 controlled synthetic multi-track unknown
association baseline。

- 输入：MC24 100 GeV FASERnu muon，5 个 xAOD events，IFT+S1+S2+S3。
- 对准参数：station 1--3 的 `dx/dy`，station 0 固定为 reference。
- propagation：只用 `q_over_p_mode=0`。local SegmentFit q/p 是固定 seed，不是可靠 measurement。
- 不复用非零点的 coordinate/residual；每个物理点重新跑 Calypso。

## Physical Capture Scan

每个点实际执行：

```text
point-specific /Tracker/Align SQLite/POOL payload
  -> persisted SCT_ClusterContainer
  -> SegmentFitRefit -> SegmentsRefit
  -> NtupleDumper tracklet / propagation export
  -> FaserActsExtrapolationTool mode 0
  -> fixed-truth WLS alignment closure
```

配置：`configs/physical_refit_capture_scan_muon.yaml`。幅度为
`0, 0.1, 1, 10, 50, 100, 250, 500, 1000 mm`；零偏移跑一次，非零幅度各跑
`mixed_a/mixed_b/mixed_c` 三个归一化方向，共 25 个物理点。WLS gate 为 25，3 次 refinement，
成功阈值为最大 movable-station 恢复误差不超过 `0.01 mm`。

关键诊断：零点、0.1 mm 和 1 mm 的 full-rank 解均为 rank 6，condition number
约 `2.03e4`，并有 27 条 active truth pairs。1 mm 的失败是严格 tolerance 失败，不是
rank loss。500 mm 的 `mixed_a` 仍有 rank 6，但误差 `0.01099 mm` 略高于阈值；其余高偏移方向
会在 WLS gate 后降到 rank 4 或 2。故在这套特定控制条件下，严格 physical capture range 为
不大于 `0.1 mm`。

每点的 `capture_scan_points.csv` 保存 available/active truth pairs、station 1--3 恢复的
`dx/dy`、分量误差、范数误差、rank、condition number 与 success。`capture_scan_station_pair_diagnostics.csv`
保存每个 station pair 的 `rx/ry/rtx/rty`、pull 与 chi2。图 `capture_scan.png` 已用 log
recovery-error 轴显示低偏移区域与高偏移 rank-loss 区域。

## 真实 Payload 上的 Synthetic Unknown Association

每个物理点都从它自己的 `refit/tracklets.root` 生成同一个随机 layout 的 overlay：100 个
synthetic events、每 event 4 条 source tracks、真实 tracklet missing probability 0.10、每站
fake Poisson mean 0.50。当前五个 xAOD events 中只有 4 条 complete source tracks，因此该样本
用于受控 robustness，不是 source-event-independent 泛化测试。

为避免 propagation 代理：overlay row 保存 `origin_run_id/event_id/tracklet_id`。针对每个
synthetic source-target candidate，从同一 physical payload 的 mode-0 Acts export 按 source
provenance 和 target station 查找 prediction；只有 target z 完全兼容时才写入 candidate。25 个点的
candidate records 均为 10,105，target-z mismatch 总数为 0；每点 111 个 source-target 组合缺少
可用 source prediction（来自原始不完整 propagation 覆盖），被显式计数而非近似。

MLP 只在 nominal 点训练。100 个 synthetic events 以固定 seed 分为 70/30；`heldout_event_ids.json`
中的 30 个 events 对 field-chi2 与 MLP 的所有 payload 都相同。zero point 的 held-out 样本有
572 个 truth-possible pairs。field-chi2 使用预先固定的 `chi2=1500` gate；nominal truth chi2
最大为 630.52，故 gate 覆盖所有 nominal truth candidates。MLP 为两层 64 维 ReLU，使用 residual、
pull、log chi2、covariance logdet、dz、local quality、hit count 与 station-pair one-hot；不输入
truth、q/p 或 injected offset。

field-chi2 的较高 purity 是固定 gate 只剩少数 survivor 的选择偏差，不能解释为实际鲁棒性。
10--50 mm 的 MLP 高 purity 同样主要来自 nominal threshold 拒绝大量 candidate；其 efficiency
已显著下降。每方向离散值见 `unknown_association_scan_points.csv`，图的 band 显示方向范围。

## 决策

现在不启动 Transformer。当前证据表明：

1. physical alignment closure 的严格 capture range 很小；
2. fixed-geometry MLP 在 10 mm 起已有明显 recall 损失；
3. 50 mm 以上两种 baseline 都无法同时维持 efficiency 与 inclusive fake rate；
4. 当前 source sample 只有 4 条物理轨迹，不能将 MLP 指标解释为独立泛化能力。

下一步应先做 Stage 2 式 misalignment augmentation/curriculum、MLP score calibration 与
candidate-gate scan，并扩展 source-event-independent MC。完成这些受控对照后再判断
Geometry-Aware Transformer 是否提供额外 capture range。
