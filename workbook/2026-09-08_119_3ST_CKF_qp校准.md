## 裁决（必须先读）

**三站 CKF \(q/p\) 不能作为后续 Yasu weak-mode 研究中的可信 reconstructed momentum observable。**

失败不是单一数字不好看，而是四个独立维度同时破冻结门控，最严重的区域是高动量 \(p\ge 2\,\mathrm{TeV}\)（\(q/p\to 0\)）以及大斜率 \(|t_x|\ge 0.010\)、\(|t_y|\ge 0.010\)：

1. **电荷符号**（主因）：合并符号一致率 \(0.928 < 0.95\)；高动量 \(0.818 < 0.90\)。243758 条 sign-flip **全部保留**。
2. **协方差未校准**：pull RMS \(955\)（门控 \([0.70,1.40]\)）；68%/95% coverage \(0.415/0.659\)（门控 \([0.50,0.86]/[0.85,0.99]\)）。中位数 pull \(-0.067\) 接近 0，均值/RMS 被极端尾巴主导。
3. **运动学依赖偏置**：\(p\in[200,500]\,\mathrm{GeV}\) 的 \(\bar z=-1.61\)；多个 \(t_x,t_y\) 层 \(|\bar z|>1\)，大斜率层 \(\bar z\sim 3\)–\(5\)。
4. **均值偏置**：合并 \(\bar z=-0.5002\)，刚好越过 \(|\bar z|\le 0.50\)。中位数几乎无偏，不能用“看起来差不多”翻案。

选择损失与 fit 失败未破门控。没有 IFT 泄漏，没有 dummy \(q/p\)，truth 未进解。**不得**靠重定义样本、丢掉 sign-flip 或高动量尾巴、只看中位数、或挑低动量区间把本阶段改成 PASS。

## 问题

第 0–1 阶段已锁定官方 `CKFTrackCollectionWithoutIFT` 并建立独立 3ST→IFT 预测链。本阶段只回答：三站拟合带符号 \(q/p\) 本身是否无偏、符号是否可靠、\(\sigma(q/p)\) / 原生 5×5 是否校准。

正式观测量与参考（看结果前冻结）：

```
q/p_fit   = WithoutIFT front() 原生 Trk::CurvilinearParameters q/p（S1，1/MeV，带符号）
σ(q/p)    = sqrt(C_44)
q/p_truth = truthParticle.charge() / |p_S1|
            p_S1 = FiducialParticleTool::getTruthMomenta(barcode)[1]
```

匹配：`TrackTruthMatchingTool`（`SCT_SDO_Map` 在 MOT 上的多数 barcode）。公式沿用 NtupleDumper tracklet 路径，参考站固定为 1。产生点 \(p\) 只诊断。斜率 \(t_x=p_x/p_z\)、\(t_y=p_y/p_z\)。

主量：\(\Delta(q/p)\)、\(z=\Delta/\sigma\)、符号一致、68%/95% coverage、pull 均值/宽度、\(\mu^+/\mu^-\) 电荷偶/奇偏置。必须看 \(E[\Delta\mid q/p_{\rm truth}]\)、\(E[\Delta\mid t_x]\)、\(E[\Delta\mid t_y]\)，不只看 \(E[q/p]\)。
