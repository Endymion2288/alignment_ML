## 1. 唯一问题、假设与防止循环论证

H：独立参考流的局部state Jacobian能将已量化的局部缺陷传到终态，并在独立数值预算内闭合全部156 endpoint向量及保存的nominal/mixed full/half差。不是只需误差方向相同、挑一个cap、降低50%或解释单个worst case。

如果每步把官方state作为reference起点，再注入该步精确缺陷，完全forced replay必然按定义复现官方终态。这是代数恒等式，**不能用它当H的证据**。本研究预测为Jacobian线性传递；对照是从真实initial state出发、不注入任何局部缺陷的独立全程非线性参考。两者未被强制相等，残余可证伪。

## 2. 数学表示及same-arc控制

## 11. 闭合的数学内容及非循环性

固定z chart的独立ODE等价于原WB94 `rhs`：令N=sqrt(1+tx²+ty²)，

```
dx/dz = tx
dy/dz = ty
dtx/dz = q*N*[ty*Bz - (1+tx²)*By + tx*ty*Bx]
dty/dz = q*N*[(1+ty²)*Bx - tx*Bz - tx*ty*By]
```

q为ACTS native q/p、B为native field，单位来自实际`Acts::UnitConstants`。新解析cell梯度/自动微分只求double软件场ODE对X的导数；独立scalar旧RHS/FD及解析常场对照核验其实现。三档Jacobian最大差4.95e-8与FD所查点最大差5.68e-12不同：FD只在468个预定点，不代表每个135355步都做了FD；其余步有三档稳定性检查。C0 cell界面仍不构成处处可导的证明。

实际误差为e_i=X_i−R_i，其中R_i是无注入reference流。由定义：

```
e_i = δ_i + F_i(X_(i-1)) − F_i(R_(i-1))
    ≈ δ_i + A_i*e_(i-1)
```

A在实际state沿局部reference计算，忽略的非线性项并非被构造为零；最终与从真实initial出发的一次完整无注入scalar reference比较。因此全矩阵小closure支持本pilot的线性vector transport近似，**不来自每步精确注入后按定义重置官方state的恒等复现**。local δ仍由已见官方轨迹计算，不是预测一个从未见过的轨迹/事件误差。

same-arc→same-z的最大X差为1.0511769232834922e-9 scaled，same-z→plane最大8.057000400185643e-9，均有独立三档/root证据。相同arc结果、固定z主gate及target-plane对照分别保留；本次没有把任意六维free-state差、四维slopes差、bound frame差或chi2互相替代。

source target frames的实际normal均为+z，station1/2/3 origins z分别47.40000000000009、1237.4000000000008、2427.4mm；依据WB96原`settings[0].targets[*].frame`，不是根据station编号猜测。实现仍按frame normal/origin求plane root；entry plane来自真实conditions min_z=-1762.3mm与WB96 source construction。free→bound差由原两份state记录，未把平面投影精确当成真实free终点精确。
