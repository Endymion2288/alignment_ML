### 代码审查结论

- **无 blocker**。当前 V1/V2/Ry/multi-DoF 管线的所有入口都正确执行 test 封存与
  validation-only 选择；route solver 与 calibration 无重复实现：
  canonical solver = `baselines/route_assignment.py`（MILP + DP fast path 的
  unit-capacity route packing）；canonical calibration = `evaluation/pairwise_metrics.py`。
- **Major-1（GPU 策略）**：`resolve_device("auto")` 静默回落 CPU：
  `training/geometry_aware_transformer.py:158-159` 与 `baselines/mlp_pair_classifier.py:68-69`
  两处重复实现；`device="auto"` 默认值散布在 5 个 dataclass、7 个 predict/load 签名、
  3 个 YAML（`physical_curriculum_mlp_muon.yaml:82`、`geometry_aware_transformer_v2_diagnostics.yaml:22`、
  `synthetic_unknown_association_muon.yaml:30`）和 2 个 CLI 默认
  （`run_frozen_association_backbone.py:341`、`audit_frozen_v1_ift_ry_routes.py:379`）。
  在无 GPU 节点上会静默 CPU 训练，与"GPU or fail loudly"策略冲突。
- **Major-2（test 泄漏风险，仅 legacy 入口）**：三个 legacy baseline 入口仍可打开 sealed
  test ROOT：`run_curriculum_mlp_baseline.py:499+577`（无条件）、
  `run_station_pair_threshold_baseline.py:391+666-669`（`--evaluate-test`）、
  `run_global_assignment_mlp_baseline.py:118+1221-1223`（不加 `--validation-only` 时）。
  它们没有 `allowed_splits` / `_audit_sealed_samples` 防护。当前 canonical 管线不受影响，
  但属于随时可能被误用的开口。loader 默认解析全部 split
  （`datasets/physical_curriculum.py:111-121`），防护是逐调用点 opt-in。
- **Minor**：`training/structured_assignment.py:463`、`training/transformer_diagnostics.py:423,466`
  仍直接读 `sample.magnitude_mm`（绕过统一 condition accessor；V3 已暂停，风险低）；
  loader 在两个 key 并存时优先 legacy `magnitude_mm`（`physical_curriculum.py:176-180`），
  与统一 accessor 意图相反；synthetic loader 不校验 manifest 级 `q_over_p_mode`；
  `datasets/propagation_loader.py:127-131` 对缺失 q/p branch 静默填 0（legacy MC22 兼容，
  使"缺失"与"mode 0"不可区分）；约 15 个 legacy 脚本按 `magnitude_mm` 分组且无 axis 校验。
- **Legacy/superseded（保留但不应再扩展）**：`baselines/multistation_assignment.py`、
  `training/station_pair_thresholds.py`、`scripts/materialize_curriculum_synthetics.py`、

## 物理结论（当前可声称与不可声称）

**可以声称**：
- 真实物理链（payload → cluster → SegmentFitRefit → NtupleDumper → mode-0 Acts）完整可用，
  rotation 确实进入 geometry/refit/propagation（±60 mrad → Δx ∓111 mm、Δtx ±0.060）。
- truth-fixed 单站 dx/dy closure 精度达 5e-13 mm 量级（小偏移、station-3 控制）。
- IFT Ry 在 ±60 mrad 可辨识，且 anchor+局部 probe 的真实有限差分迭代可恢复到 <1 mrad
  （10-event、truth-fixed）。
- dx/dy 大错位下（≥5mm）physical candidate graph 保留 truth chain（overlay recall=1.0），
  而 frozen association（MLP/V1/V2/V3）全部无法满足 primary gate——association 是瓶颈，
  不是 candidate 丢失。
- Ry 至 ±60 mrad 时所有合理模型（MLP+route、V1 full/no-context、V2 BCE）在 validation 上
  均过 primary gate——Ry 不是当前 association 失效边界；V3 structured-margin 失败已确证。

**不能声称**：
- 不能声称 Transformer 扩大了 capture range（dx/dy 上 V1 full-context 未优于 no-context；
  Ry 上所有模型都没到失效边界）。
- 不能声称 multi-DoF（dx+dy+Ry）联合可恢复：10-event joint closure rank 满秩但统计不稳定
  （dx 符号翻转、LOEO 波动 -2.8..+9.55mm），capture_success=false。
- 不能声称 raw physical candidate coverage 是 100%（Ry 大样本 raw recall ≈0.95，0->1 是
  主要损失对；overlay 的 1.0 是"只选 complete truth track"后的分母）。
- 不能声称 unknown-association alignment、iterative loop、6-DoF、layer/module、real-data
  策略中任何一项已成立。
- 历史 sealed test 结果只是单一样本的一次性冻结评估，不能外推。
