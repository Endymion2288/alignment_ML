## 1. 科学问题（唯一）

源协方差已在 WB86 下闭合之后：

**`C_target = J_transport C_source J_transport^T + process_noise` 能否描述 `e_target = 传播拟合态 − 目标面 truth`？**

成功标准不是 alignment 变好，而是 target-surface covariance closure。

## 3. Stage 拆分（预注册）

**Part A**（确定性传输，无 process noise）：

`C = J_geom C_src_WB86 J_geom^T`

**Part B**（process noise）：Highland MS，`x/X0=0.05` / gap（量级 SCT station，
**不是** chi2 拟合），动量取生产 tracklet `|q/p|`。

四种 mode：

| mode | 含义 |
| --- | --- |
| 0 | 现有生产 `C_prop` |

## 4. 结果

样本：construction (0,1)/(0,2)/(0,3) = 413 / 405 / 390；validation = 302 / 303 / 293。

### 4.1 Part A：Jacobian 自洽（`J e_source` vs `J C J^T`）

**6/6 通过**，两个 split 一致。

| split | pair | χ²/ndof | median | frac>4 | calibrated |
| --- | --- | --- | --- | --- | --- |
| construction | (0,1) | 0.996 | 0.849 | 0.024 | 是 |
| construction | (0,2) | 1.00 | 0.849 | 0.025 | 是 |
| construction | (0,3) | 1.01 | 0.852 | 0.026 | 是 |
| validation | (0,1) | 1.00 | 0.856 | 0.023 | 是 |
| validation | (0,2) | 0.989 | 0.842 | 0.026 | 是 |
| validation | (0,3) | 0.969 | 0.845 | 0.024 | 是 |

已验证的源协方差在几何 4D 传输下自洽。失败不在 `J`，而在 `e_target` 相对
`J e_source` 的剩余（主要 `y/ty`，随 `1/p` 变大）。

### 4.2 `e_target` 四 mode（全部失败）

| split | pair | mode0 χ² / pencil | mode2 χ² / pencil | mode3 χ² | cal |
| --- | --- | --- | --- | --- | --- |
| construction | (0,1) | 7224 / 727 | 5.24e5 / 1.08 | 5.43e4 | 否 |
| construction | (0,2) | 4.61e4 / 9853 | 5.43e5 / 1.12 | 2.06e4 | 否 |
| construction | (0,3) | 1.50e5 / 1.35e4 | 1.36e6 / 1.22 | 2.87e4 | 否 |
| validation | (0,1) | 799 / 1.79e4 | 4.26e4 / 1.06 | 3811 | 否 |
| validation | (0,2) | 2935 / 1.94e4 | 3.17e5 / 1.07 | 1.12e4 | 否 |
| validation | (0,3) | 4.81e4 / 4.39e4 | 7.40e5 / 1.09 | 1.32e4 | 否 |

mode 1（加回 dummy q/p ΔC）把 **median** χ² 拉回 ~0.7–1.0，但 pencil 仍是
727–43890×，均值 χ² 仍失败。这不是可提升的生产模型。

mode 2 把 pencil 修到 ~1，同时把精密面 χ² 打到 10⁴–10⁶：删 dummy q/p **不是**
最终方案。

mode 3 Highland 使 χ² 下降约 10–50×，仍远高于 gate；未对 chi2 调参。

### 4.3 q/p 审计

- dummy q/p **没有**物理意义（直线 SegmentFit 未约束动量）。
- 穿过磁场的传输**需要**物理 q/p。
- 禁止把删列当作最终方案。
- 禁止把 truth q/p 当作 real-data 解。

## 5. 决策

**`faseracts_transport_covariance_not_validated`** /
**`q_over_p_uncertainty_semantics`**

- 源协方差已不是限制因素（WB86）。
- 4D 确定性传输相对 `J e_source` 已闭合。
- 生产 `C_prop` 以及所有预注册的 `J C J^T (+ Highland)` 都不能闭合 `e_target`。
- 机制：dummy q/p 协方差不是物理动量不确定度；物理 q/p 又是磁场传输所必需，
  本战役未构造该先验。并行：ACTS process noise 关闭，Highland 不足。
- 不进入 Measurement Model V2，不进入 alignment，不写 geometry。
