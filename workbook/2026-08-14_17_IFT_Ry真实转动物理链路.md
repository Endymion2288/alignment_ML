## 从 Calypso 源码确认的条件与 ACTS 语义

检查 `TrackerAlignDBTool::stationAlignment` 后确认 payload 常数严格为：

```text
[dx_mm, dy_mm, dz_mm, rx_rad, ry_rad, rz_rad]
```

单位为 mm/rad，station transform 为全局
`T * Rz * Ry * Rx`。`station:0` 对应 IFT。`FaserSCT_AlignCondAlg` 生成
`SCTAlignmentStore`；`FaserActsAlignmentCondAlg` 从它构造
`FaserActsAlignmentStore`；`FaserActsDetectorElement::transform` 从 geometry context 的
alignment store 获取 cached aligned transform。因此当前链路确实让 segment refit 和 ACTS
surface 同时随 payload 倾斜，不是只改 residual 或 tracklet 坐标。

## Closure 与正在运行的批处理

以独立的 `+/-10 mrad` physical probe 做 central finite-difference WLS 时，`+60/-60 mrad`
分别恢复为 `+54.2246/-54.8091 mrad`，绝对误差 `5.775/5.191 mrad`；normal-matrix rank 都为 1，
condition number 为 1。用独立的 `0,+/-10,+/-25,+/-40 mrad` physical response 做 held-out 曲线
拟合也没有达到 1 mrad：二次拟合的 `+60/-60` 误差为 `4.233/7.425 mrad`。结论是该 10-event
sample 的 `R_y` 参数可辨识，但单步 closure 尚未达到 1 mrad，不得声称已经闭合。

为检验真正的局部迭代而不是提高 surrogate 阶数，已冻结独立 probe
`0,+/-45,+/-50,+/-55 mrad`。它们将用于以 `+/-50 mrad` 为 anchor 的真实 finite-difference
Newton/WLS step，而 `+/-60 mrad` 仍只作为 held-out observation。由于交互会话会截断 Athena
子进程，新增可复用的单扫描 Condor worker/submitter；该 refinement 已提交为 Condor cluster
`991602`。

该 refinement 的 7 个 point 已全部完成，`|R_y|=45/50/55 mrad` 的 raw candidate
truth-chain recall 仍均为 1.0。使用 `+50 mrad` anchor、`+45/+55 mrad` local physical probe
和从未进入导数估计的 `+60 mrad` observation，恢复值为 `+60.06898 mrad`，absolute error
`0.06898 mrad`；负号一侧使用 `-50 mrad` anchor、`-55/-45 mrad` probe 后恢复
`-60.41250 mrad`，absolute error `0.41250 mrad`。二者 normal-matrix rank=1、condition

physical closure，不是多项式或 coordinate surrogate。结论：大范围一次 linearization 不足，

## 已完成的冻结 MLP/V1/V2 route-level 对照

为让 MLP 与 V1/V2 使用完全相同的四站 route 定义，新增了 Condor `mlp_route` 后处理分支：它只能
接受一个已完成的 MLP checkpoint 和一个 validation-only station-pair calibration，worker 调用
`scripts/evaluate_pairwise_mlp_route_validation.py`，不训练、不重新 calibration，只在 validation 上按
预注册 grid 选择相邻站 route threshold/unmatched penalty。提交器和 worker 的输入契约均检查
`train/validation`、显式禁止 `test`、并限制 GPU capability >= 7.5（保留 H100/A100/L40/RTX）。

提交后的 Condor `991614` 在 H100L MIG 上正常结束（exit 0，33 分钟，无 stderr）。输出
`outputs/ift_ry_mlp_route_validation_v1` 记录：只加载 validation、`test_events_loaded=false`、
`test_artifacts_opened=false`、`calibration_refit=false`；冻结 checkpoint/calibration SHA-256 与输入
文件一致。MLP 的 MLP feature view 与 `residual_v1` reference view 有相同 physical candidate endpoint，
candidate membership digest 已存档；没有用 feature encoding 改变 candidate graph。
