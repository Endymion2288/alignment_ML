### 4.2 Stage 1 — covariance eigenstructure / whitening audit（H2 主线）

WB78 已观察：calibration 零 candidate χ² ≈ 2.00e6（378 pairs × 4 = 1512 dof，χ²/dof ≈ 1322），但对角 marginal pull 很小（x/y/tx/ty RMS pull 均 < 0.1）。这强烈提示 χ² 由 combined covariance 的近奇异相关方向主导。

对每个 pair 的 combined 4×4 covariance C 做完全只读审计：eigenvalues、condition number、correlation matrix、smallest-eigenvalue direction、residual 在 covariance eigenvector 上的投影、按 eigenmode 的 Mahalanobis 贡献、x/y/tx/ty marginal pull、按 pair type (0,1)/(0,2)/(0,3)、按 run 14973/14974。

**Whitening 检验（主 gate）**：z = L⁻¹(r − m_cell)，其中 m_cell 是 per-(run, station-pair-type) 的 coherent mean（diagnostic-only 的 alignment-bias 代理，**绝不**作为新 residual 定义或 alignment input）。若 frozen covariance 正确描述 coherent mean 之外的涨落，则 whitened residual χ²/ndof = O(1)。

- **预注册 gate（对模型宽容）**：`whitened_chi2_resid / ndof ≤ 4.0`，ndof 扣除估计的 cell mean（每个非空 run×pair cell 扣 4）。
- 报告（非 gate）：完整 eigenstructure、correlation、χ² 按 covariance eigenmode 的集中度（特别是 smallest eigenmode 占比）、marginal pull、condition 分布、whitened residual 的经验 Cov(z) 特征值/condition。

去均值只用于区分 "large coherent mean"（可能是 alignment）与 "grossly wrong covariance shape"（covariance mismatch）；即使最宽容地去掉 coherent mean 后 whitened χ² 仍巨大，即可判定 covariance model 不充分。

### 7.2 H2 — covariance/statistical-model adequacy：**决定性失败**

- 零 candidate χ² = 2.00×10⁶（1512 dof，χ²/ndof = 1322.5）。
- **99.74% 的 χ² 集中在最小 covariance eigenmode**；combined covariance 在数值上近奇异（condition 中位数 2.3×10¹²，p95 4.1×10¹³；**99.7% 的 pair condition > 10⁸**；最小特征值中位数 6.2×10⁻⁷）。
- **Whitening 检验（主 gate）**：去掉 per-(run, pair-type) coherent mean 后，whitened residual χ²/ndof = **1058.46 ≫ gate 4.0**。即使最宽容地去掉 coherent alignment mean，frozen covariance 也完全不能描述 residual 涨落。whitened residual 经验 Cov(z) 特征值 [1.08, 4.18, 21.27, 4159.09]（condition 3841，应≈1）。
- **关键机制（已核实）**：full 与 diagonal covariance 给出**逐位相同**的信息矩阵 H、特征值与 β（‖H_full−H_diag‖/‖H_full‖ = 0.0）——近奇异方向是 **alignment-blind**（在设计矩阵左零空间方向），它把 χ² 放大 ~1750× 却不改变 alignment 解。
- **对角 counterfactual 对照**：相同 marginal variance、去掉 off-diagonal 后 χ² = 1140.2（χ²/ndof = **0.75**，健康）。问题被精确隔离到 **off-diagonal 相关结构**——combined covariance 声称沿近奇异方向有 ~10⁶× 的精度，而真实 residual 在该方向有正常量级涨落，被放大成巨大 χ²。
- `inv(C)` 数值不可靠：最差 pair（condition 1.6×10¹⁴）‖C·C⁻¹−I‖max = 5.7×10⁻⁶。
- **Cross-run 经验协方差不可复现**：(0,2) generalized-eigenvalue RMS log-deviation = 1.274 > gate ln(3)=1.099（(0,1) = 1.058 通过）。
