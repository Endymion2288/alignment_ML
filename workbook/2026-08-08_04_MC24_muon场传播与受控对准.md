# 2026-08-08：MC24 muon 场传播、受控对准与 synthetic overlay

## 本轮目标与边界

按当前研究优先级，不等待四站 electron MC，也不开始 Transformer。保留 MC22 100 GeV
electron 作为 station 1--3 的 exporter/covariance/loader smoke test；以已确认含
IFT+1+2+3 的 MC24 100 GeV FASERnu muon 为主样本，先验证 q/p、含磁场 propagation、
固定 truth 的 station-level alignment closure，以及可控 synthetic multi-track 输入。

## q/p 与 field-aware propagation

1. 对 MC24 前 5 个 event 的 canonical 输出，得到 24 条 tracklet，station 计数为
   0/1/2/3 = 5/6/8/5；MC22 electron 的旧 canonical 输出仍可正常加载，10 event、28
   条 tracklet、station 1/2/3 = 10/13/5，28/28 covariance 正定。
2. MC24 的 24/24 tracklet 有限且非零 `q_over_p_per_mev`，都与同一组 reconstructed
   TrackParameters 导出的 charge/p 完全相同；q/p covariance validity branch 存在，
   24/24 variance 有限且非负。
3. 这只能证明 branch 的单位/符号/序列化可用，不能证明动量或 q/p uncertainty 已由
   独立 truth 标定。导出的 q/p variance 全部约 `5e-6 1/MeV^2`，需要后续检查其
   parameter convention 和物理量级。
4. `FaserActsExtrapolationTool` 已实际用于 exporter 的 36 条 truth-matched pair，
   全部 success 且有 covariance，覆盖 `0->1`、`0->2`、`0->3`、`1->2`、`1->3`、
   `2->3`。本次 C++ 中 particle hypothesis 明确为 muon，不能直接外推到 electron
   结论。
5. field-aware 4D chi-square 中位数为 77.67，straight-line 为 450.38；均值分别为
   3005.05 和 21388.64。场传播相对直线明显改善，但 chi-square 远未接近理想闭合，
   当前只确认 propagation 数据链路和相对比较，不能宣称 covariance 或 nominal
   geometry 已完成物理闭合。

## 受控 alignment closure

1. 新增 `alignment/closure.py`。station 0 固定为 reference，station 1--3 只拟合
   `delta_x, delta_y`；使用 field-aware pair 的二维 combined covariance 做 weighted
   least squares。
2. 注入定义明确为 coordinate-reporting residual 注入：
   `r_injected = r_nominal + delta_target - delta_source`。求解前扣除名义 residual，
   所以此实验不受当前名义 residual 未闭合的直接影响。
3. 显式零噪声注入：S1=(0.10,-0.06) mm、S2=(-0.08,0.12) mm、S3=(0.05,0.10) mm。
   三次 refinement 使用 36/36 pair，normal-matrix rank=6，最大恢复误差
   `5.18e-14 mm`，为数值精度。
4. gate=25、100 个随机方向/幅度的 scan：0--100 mm 的 capture fraction 都为 1；
   500 mm 为 0.34，1000 mm 为 0.05。该范围主要由当前很宽的 propagated covariance
   决定，绝不是 detector 物理 capture range。它只验证 baseline-subtracted
   residual-level gate/optimizer 的受控行为。
5. 物理下一步是校准 propagated covariance，并在 ACTS surface/geometry 上真正注入
   station transform 后重跑 propagation；完成前不比较 joint model 的真实 capture
   range，也不启动 Transformer。

## Synthetic multi-track 数据

1. 新增 `datasets/synthetic_overlay.py` 和 CLI。每个源轨迹要求四站都有 truth-match
   fraction >=0.99 的 segment；重复 segment 按 match fraction、local chi2、tracklet ID
   做确定性选择。
2. 每个 synthetic event 重命名 source truth ID，独立随机丢失 true tracklet，并按站从
   原始 local tracklet pool 抽取 Poisson fake/background，fake 的 truth ID 为 -1。
3. 用 seed 20260808 生成 100 个 event、每 event 4 条 source track、missing=0.10、
   fake mean=0.5/station：共 1,642 条 row，其中已知 truth 1,449 条、丢失 true row
   151 条、fake/unknown 193 条；四站均存在，q/p 可选字段保留。
4. 源样本仅有 5 条物理 trajectory，被重复使用。因此它只用于数据管线和受控 association
   ablation；未来训练/评估必须按 source event 划分，不能将它作为无偏物理性能结果。

## 2026-08-09 补充：q/p truth 审计与条件 payload 边界

本节的 q/p 结论取代上文任何“local q/p 可直接作为测量量”的解读。

1. V4 重新审计 24 条 MC24 tracklet；与同一 reconstructed TrackParameters 的
   charge/p 完全一致只证明 exporter 序列化自洽，不能作为独立物理验证。
2. 22 条具有有限 truth q/p 的 tracklet 中，只有 14 条符号一致，比例为
   `0.6364`；local q/p uncertainty 相对 truth q/p 的中位数为 `223.61`。
   因此当前 reconstructed local q/p 不能作为 V1 local measurement，只保留作
   global-track latent parameter 或 MC 审计量。
3. 场传播输出区分三种模式：mode 0 为 reconstructed q/p；mode 1 为
   reconstructed position/direction 加 MC truth q/p 且去除 q/p seed covariance；
   mode 2 为完整 truth-state transport。当前 coordinate-level closure 使用 mode 1，
   它是 MC 控制量，不可部署到真实数据。
4. V4 中 mode 0 的 field-aware 4D chi-square 中位数为 `60.05`，straight line 为
   `432.03`；mode 1 的中位数为 `427.55`。这证明场传播数据通路和相对比较可用，
   但不证明 covariance 已标定，也不能把现有 chi-square 当成物理 association gate。

## 2026-08-09 补充：Calypso 条件 payload 与受控 closure

1. 扩展工作区的 `TrackerAlignDBTool`，使 `station:<id>` 常量可写入 global station
   transform；V1 manifest 固定六分量顺序为
   `[dx_mm, dy_mm, dz_mm, rx_rad, ry_rad, rz_rad]`，仅允许前两项非零。
2. 已实际写入 station 3 的 `+1 mm` x 偏移 SQLite/POOL payload，并在 MC24 exporter
   中加载。日志确认 `/Tracker/Align` SQLite override、`SCTAlignmentStore` 与
   `FaserActsAlignment` 均已创建，故条件链本身有效。
3. 对同一个 xAOD 重新导出后，station 3 的持久化 tracklet x/y 与 nominal 完全相同，
   propagation prediction 的最大 x/y 差异分别仅为 `6.4e-10 mm` 和 `3.3e-9 mm`。
   原因是当前 exporter 读取持久化 local segment state，不会从 raw hits 在偏移 geometry
   下重新 fit。不可把该 rerun 描述成 physical deformed-geometry reconstruction。
4. 因而 V1 使用独立的 coordinate-level surrogate：
   `x' = x + dx_station, y' = y + dy_station`，不改变 slope/covariance。为避免名义
   propagation source state 与偏移 source state 不一致，只保留 source 为 reference
   station 0 的 pair。
5. 对 station 3 `+1 mm` payload，30 条 truth-matched pair 中有 15 条
   reference-source pair；观测 increment 与 manifest 的最大差异为 `8.9e-16 mm`，
   normal-matrix rank=6，恢复 station 3 为 `[+1.0, 0.0] mm`。
6. 100 个随机方向、gate=25、三次 refinement、`0.01 mm` tolerance 的
   coordinate-level capture scan：0--5 mm 的 capture fraction 为 1.00；10 mm 为
   0.39，20 mm 为 0.05，50 mm 为 0.01。这只描述该 surrogate 的受控范围，不能称为
   探测器物理 capture range。
