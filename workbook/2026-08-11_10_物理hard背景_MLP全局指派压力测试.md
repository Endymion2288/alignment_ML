## hard fake 定义

- 每个 synthetic event 叠加三个彼此独立的 source track，并保留 missing tracklet。
- random easy fake 要求大的 mode-0 Acts chi2。
- hard fake 来自同一个真实 conditions payload 的 field-aware mode-0 Acts 候选；若
  保留的 truth endpoint 存在，要求
  `1.10 <= hard_chi2 / truth_chi2 <= 10.0`。
- 审计确认不存在比保留 truth counterpart 更兼容的 hard fake。
- 默认完整压力密度：每个非参考 target station 平均 `0.50` 个 hard fake。

这避免了“随机远离 fake”过易或“hard fake 人为优于 truth”过度对抗的两种偏差。

## validation-only 基线结果

主运行点事先固定为：nominal efficiency >= `0.70`、inclusive purity >= `0.95`、
inclusive fake rate <= `0.05`。所有下表均只使用 validation 选控制量，test 未打开。

| 方法 | 最佳质量运行点 | Efficiency | Inclusive purity | Fake rate | 结论 |
| --- | --- | ---: | ---: | ---: | --- |
| shared `state_augmented_v2` | Sinkhorn + Hungarian，gate 250 | 0.4476 | 0.9580 | 0.0420 | 未通过 |
| shared v2 + station-pair temperature | Sinkhorn + Hungarian，gate 250 | 0.4722 | 0.9523 | 0.0477 | 未通过 |
| exact four-station flow | ungated，10,000 hypothesis 上限 | 0.4205 | 0.9517 | 0.0483 | 未通过 |
| 六个独立 pair MLP | pair temperature，gate 250 | 0.4361 | 0.9521 | 0.0479 | 未通过 |
| shared v2 + station-pair threshold vector | Sinkhorn + Hungarian | 0.5986 | 0.9509 | 0.0491 | 最强但未通过 |
| `state_hitpattern_v4` | 持久化 layer-side bit | 0.3576 | 0.9597 | 0.0403 | 负 ablation |

较低 hard 密度的受控点也未通过：密度 `0.10` 和 `0.25` 的最佳质量 efficiency
分别为 `0.3790`、`0.3851`。因此不能将失败简单归因于默认 `0.50` 的背景数量。

## 指派和校准审计

1. 已比较 greedy、Hungarian、dustbin Hungarian、Sinkhorn 后 Hungarian，以及
   four-station min-cost-flow 式全局 hypothesis 选择；后者没有超过 pairwise
   dustbin/Sinkhorn 的最佳结果。
2. standard global threshold 会过度压制难 station pair。于是只对 validation 做有界
   station-pair vector 搜索：5 个阈值、2 个初值、2 轮 coordinate descent、3 个
   unmatched penalty。
3. 最佳 vector 按 `0->1, 0->2, 0->3, 1->2, 1->3, 2->3` 为
   `0.35, 0.60, 0.60, 0.20, 0.20, 0.20`，unmatched penalty=`1`，
   Sinkhorn temperature=`0.5`。
4. 该结果将 nominal efficiency 提升到 `0.598557`，但仍低于 0.70；其 pairwise
   score-edge truth retention 在 `0->2` 和 `0->3` 仅为 `0.06822`、`0.14162`，
   而短基线 pair 约为 `0.70--0.93`。

因此当前主要瓶颈是 S0 到远端站的真实物理长基线 pairwise score separation，而不是
greedy matching、单一 temperature 或缺少全局一对一约束。

## hit pattern 审计

Calypso 的 `NtupleDumperAlg.cxx` 已核对：`Tracklet_hit_pattern` 是六位
SCT layer-side occupancy pattern，bit 为 `2 * layer + side`。训练/验证值在
`[15, 63]`。将 source/target 的 12 个 bit 加入 `state_hitpattern_v4` 后性能下降，
没有把它静默加入主模型。

## 结论与下一道门槛

- core nominal pilot（无 field-aware hard fake）此前已通过封存测试；它不能代表完整
  physical background。
- 完整 physical hard-background 下，所有当前 pairwise MLP + global assignment
  基线仍未达到 nominal 主运行点；因此 test split 继续封存。
- 当前不应启动 Transformer。下一步应先针对 S0 长基线进行可解释的物理特征、source
  覆盖和 score calibration 诊断，且任何修复都必须沿用真实 payload/refit/Acts、严格
  source 隔离和 validation-only 选择规则。
