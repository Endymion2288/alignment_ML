## 1. 科学问题（唯一）

**WB84 定位的两个确定性 GetState 修复，是否足以恢复 WB83 Stage A 的源协方差契约？**

成功标准不是 alignment 变好，而是证明这两个 bug 是 WB83 失败的充分原因。

## 2. 起始状态审计（已完成）

`load_config` 对 WB81–WB84 做 SHA 校验（config + 决策产物 + 冻结决策/机制）：

- WB81：`faseracts_propagated_covariance_not_calibrated` / `overestimated_transported_fit_covariance`
- WB82：`existing_mc_real_wide_ty_support_validated`（`floor_muon_100120`）
- WB83：`source_tracklet_fit_covariance_not_calibratable` / `position_xy_swap_with_slope_miscalibration`
- WB84：`deterministic_segmentfit_get_state_transform_bug` / `coordinate_convention_mismatch_and_jacobian_sign_error`

Stage A 数据与 gate 与冻结 WB83 **逐字相同**（construction：100043×3+100044×2；validation：100047×2+100048×2；station 0–3；`chi2/ndof≤4`；`Cov(z)` 与广义特征值 ∈ [0.25,4]）。篡改 gate 会被 `ConfigError` 拒绝。

## 3. 修复范围（封闭）

只允许：

1. Curvilinear 槽位：`loc1 = -y`，`loc2 = +x`
2. Jacobian 符号：`dφ/dtx = -ty/r²`（旧值 `+ty/r²`）

禁止：scale factor、经验重标定、chi2 调参、残差修正、station 相关标定、改中心预测。

实施：离线确定性变换
`C_rep = J_rep J_buggy^{-1} C_exp J_buggy^{-T} J_rep^T`。`e_source` 使用未改的拟合态。

## 4. 结果（`source_covariance_closure_before_after.json`）

Baseline 复现 WB83：8/8 cell 失败，median chi2/ndof ~ 360–437。

修复后（3230 tracklet，0 次反演失败）：

| split | station | chi2/ndof | median | frac>4 | calibrated |
| --- | --- | --- | --- | --- | --- |
| construction | 0 | 1.00 | 0.838 | 0.026 | 是 |
| construction | 1 | 3.68 | 0.851 | 0.026 | **否** |
| construction | 2 | 0.987 | 0.849 | 0.015 | 是 |
| construction | 3 | 0.973 | 0.824 | 0.022 | 是 |
| validation | 0 | 1.11 | 0.826 | 0.031 | **否** |
| validation | 1 | 0.932 | 0.784 | 0.022 | 是 |
| validation | 2 | 0.910 | 0.820 | 0.008 | 是 |
| validation | 3 | 1.02 | 0.844 | 0.025 | 是 |

典型 tracklet 契约已恢复：全样本 median chi2/ndof = 0.83；修复后再做位置 XY swap，median chi2 恶化到 ~300（交换已被纠正）；`var(ty)` 边际比 ~1。

两个失败 cell 只失败在均值协方差本征 gate（`Cov(z)` 最大特征值或广义特征值下限）。原因是 MEAN `C_yy` 被 1–2 条 `|t·z|<0.99` 大角度径迹抬高（单条 `C_yy` 可贡献该 station 一半的 Σ `C_yy`）。这些 cell 的 **median** `C_yy` 仍与经验 y RMS（~0.010 mm）一致。这不是残余 XY 交换，也不能用 scale factor 处理。

## 5. 决策

**`segmentfit_getstate_repair_insufficient`**

- WB84 的两个 bug 是 WB83 失败的**主导**原因（6/8 cell 通过）。
- 它们还不是每个 station/split 上冻结均值 gate 的**充分**原因。
- 剩余结构：`mean_cyy_inflation_on_large_angle_subset`（束流槽位映射在 `|t·z|<0.99` 分支上不是完整 Athena Curvilinear 架）。
- `measurement_model_validated = false`
- `measurement_model_v2_discussion_allowed = false`
- 不进入 Stage B / FaserActs / Frozen-V2 / alignment。
